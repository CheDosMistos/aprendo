## Objetivo

Construir un groove básico sin introducir más dificultad rítmica de la necesaria.

La novedad no es la rejilla: es **mantener tres funciones distintas al mismo tiempo**.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — GROOVE BASE A

<div data-notation-score data-score-src="/bateria/notation/f4/u5/f4-u5-l1-groove-base-a.musicxml" data-score-title="Unidad 5.Lección 1 — Groove Base A" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

La partitura usa dos voces:

- **voz de tiempo:** hi-hat cerrado en ocho corcheas;
- **voz de soporte:** bombo en 1 y 3, caja en 2 y 4.

Esto activa tres extremidades: mano de tiempo, mano de caja y pie de bombo.

No hay pie izquierdo en movimiento. No hay fills ni variaciones.

## Construcción por capas

1. Hi-hat solo.
2. Hi-hat + caja.
3. Hi-hat + bombo.
4. Groove Base A completo.
5. Si aíslas una capa, vuelve pronto al conjunto.

La práctica por partes sirve para diagnosticar; **no es el destino final**.

## Qué escuchar y sentir

`PULSO / SUBDIVISIÓN / MANO DE TIEMPO / CAJA / BOMBO / TENSIÓN`

- **PULSO:** ¿los cuatro pulsos siguen reconocibles?
- **SUBDIVISIÓN:** ¿las corcheas permanecen regulares?
- **MANO DE TIEMPO:** ¿cambia al entrar caja o bombo?
- **CAJA:** ¿2 y 4 caen dentro de la rejilla?
- **BOMBO:** ¿1 y 3 alteran la mano de tiempo?
- **TENSIÓN:** ¿aprietas más al coordinar?

## Metrónomo

Empieza en una condición cómoda que permita escuchar cada capa. **No existe BPM de aprobado**.

## MÍNIMO PARA AVANZAR

- reconoces las tres funciones;
- el patrón completo puede mantenerse varios compases;
- la rejilla de corcheas no colapsa sistemáticamente;
- puedes identificar una capa problemática;
- conservas una configuración corporal sostenible.

## Registrar esta práctica

Anota `capa añadida → síntoma → correctivo → efecto`.
