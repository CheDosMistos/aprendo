## Qué evalúa

Este Evaluación no pregunta cuántas combinaciones puedes ejecutar. Evalúa si la independencia **funciona dentro de música**.

Criterio aprobado de esta unidad:

> **MANTENER UNA CAPA FUNCIONAL ESTABLE MIENTRAS OTRA VARÍA DENTRO DE UNA TAREA MUSICAL ADECUADA SIN COLAPSO DE PULSO.**

## Condición previa

Antes de usar la ruta principal debe estar abierta puerta de entrada:

- coordinación básica de cuatro extremidades FUNCIONAL;
- subdivisión binaria y ternaria FUNCIONAL;
- ostinato básico estable.

Si todavía no lo está, el resultado correcto es volver a la ruta de consolidación. Eso no se considera un fracaso de calendario.

## Evidencia requerida

### 1. Funciones identificadas
Explica qué función cumple cada capa.

### 2. Versión base
Ejecuta la tarea sin la variación y registra una referencia de tiempo, sonido y relajación.

### 3. Variación controlada
Añade una voz o función variable dentro de un vocabulario delimitado.

### 4. Continuidad
La capa base debe permanecer reconocible y el pulso no debe deformarse para acomodar la variación.

### 5. Reducción inteligente
Si la combinación se degrada, demuestra que sabes reducir una variable sin destruir la función musical.

### 6. Retest
Después de un bloque de aislamiento vuelve al groove, comping, textura o fragmento de repertorio relacionado.

## MÍNIMO PARA AVANZAR

- puerta de entrada está abierta para esta tarea;
- la capa base se mantiene funcional y temporalmente estable;
- la voz secundaria varía sin colapso de pulso;
- sonido y dinámica siguen siendo controlables;
- puedes volver a la versión base;
- detectas qué capa falla primero cuando aparece un problema;
- sabes aislar y recombinar el cuello de botella;
- existe transferencia a una tarea musical;
- no dependes de un BPM de aprobado.

## COMPETENTE/FUNCIONAL EN EL CONTEXTO DE esta unidad

La evidencia es especialmente sólida cuando además:

- varias variaciones sobreviven sin convertir la base en una aproximación;
- puedes cambiar foco auditivo entre capas;
- una modificación de posición u orquestación no altera involuntariamente el tiempo;
- el correctivo aislado produce una mejora observable en música;
- puedes decidir conscientemente no usar una combinación aunque seas capaz de tocarla.

Una sola tarea no certifica «independencia avanzada universal».

## AMPLIACIÓN

- aumenta gradualmente el vocabulario de la voz variable;
- alterna dos capas base conocidas;
- aplica la misma lógica a otro contexto musical;
- usa legalmente un recurso externo seleccionado por habilidad y compara transferencia;
- explora una superposición más exigente sólo si sigue siendo clara la distinción conceptual y no invade el núcleo de Fase 7.

## Frontera explícita

Este Evaluación **NO certifica**:

- independencia máxima;
- polirritmia profunda;
- polimetría;
- modulación métrica;
- dominio de *4-Way Coordination*, Dawson, Chapin o *The New Breed*;
- virtuosismo;
- Hito 7.

> **SI LA COMBINACIÓN SOBREVIVE PERO LA MÚSICA EMPEORA, NO ES TODAVÍA UNA VICTORIA DE INDEPENDENCIA FUNCIONAL.**

**No existe BPM de aprobado.**
