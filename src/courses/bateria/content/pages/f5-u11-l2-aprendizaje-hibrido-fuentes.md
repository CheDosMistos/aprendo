## Objetivo

Aprender Pieza C usando varias fuentes **con intención**, no por acumulación.

> **APRENDIZAJE HÍBRIDO ≠ MIRAR TODO A LA VEZ.**

Cada fuente debe resolver una pregunta diferente.

## 1. Escucha — ¿qué relación musical percibo?

Usa el playback original para responder:

- ¿dónde cambia claramente la energía?;
- ¿qué se mantiene estable?;
- ¿qué transición se reconoce sin mirar?;
- ¿qué sección parece necesitar menos densidad?;
- ¿qué detalle todavía no puedes describir con seguridad?

La escucha no tiene que darte nombres perfectos. Debe orientarte.

## 2. Chart — ¿dónde estoy y qué viene después?

Usa el chart para:

- confirmar la forma;
- anticipar entradas;
- localizar cues;
- decidir dónde un fill tiene función;
- evitar depender de memoria golpe por golpe.

Jerarquía de lectura:

`TIEMPO → FORMA → ENTRADA → GROOVE → DINÁMICA → FIGURE/FILL → DETALLE`

Si un detalle escrito destruye la continuidad, vuelve temporalmente a una versión más simple.

## 3. Memoria — ¿qué necesito recuperar sin apoyo?

No memorices 32 compases como 32 objetos separados.

Memoriza **chunks funcionales**:

- `INTRO = establecer`;
- `A = groove base`;
- `B = contraste`;
- `A' = regreso con una variación`;
- `OUTRO = reducir y cerrar`.

Después añade sólo los cues cuya función comprendas.

> **MEMORIA ÚTIL = ESTRUCTURA + FUNCIÓN + SEÑALES.**

## 4. Análisis — ¿dónde está el verdadero riesgo?

Marca como máximo tres puntos de riesgo:

- transición A → B;
- retorno B → A';
- preparación del cierre.

Para cada punto escribe:

`qué debería ocurrir → qué podría fallar → qué referencia permite recuperarlo`.

Ejemplo:

`B → A' → volver al groove base → puedo sobreactuar el fill → referencia = primer pulso de A'`.

## 5. ESENCIAL AHORA — circuito de cuatro pasadas

### Pasada 1 — sólo escucha
No toques. Formula hipótesis.

### Pasada 2 — sólo chart
Sin playback, recorre forma y cues marcando pulso.

### Pasada 3 — memoria
Cierra el chart y recita la forma completa.

### Pasada 4 — interpretación
Toca una versión sostenible. Sólo después revisa qué fuente faltó cuando apareció un error.

## 6. Recuperación activa

Antes de volver a mirar el chart, intenta responder de memoria:

1. ¿qué sección sigue a B?;
2. ¿dónde está el cue de cierre?;
3. ¿qué cambia realmente entre A y A'?;
4. ¿qué detalle puedes omitir sin perder la pieza?;
5. ¿qué detalle NO puedes omitir porque tiene función formal?

La respuesta no tiene que ser perfecta. El intento de recuperación revela qué representación interna está disponible.

## 7. Error frecuente — “el score manda”

El score es una fuente, no el objetivo.

Si puedes tocar cada golpe escrito pero pierdes la forma, el aprendizaje de repertorio todavía no es funcional.

Si mantienes forma y tiempo con una versión simplificada consciente, tienes una base más útil sobre la que recuperar detalle.

## Criterio de avance

Puedes explicar:

- qué aprendiste por escucha;
- qué aprendiste por chart;
- qué decidiste memorizar;
- qué analizaste como punto de riesgo;
- qué simplificación usarías para salvar continuidad.

Después puedes tocar bloques largos sin depender constantemente de una sola fuente.
