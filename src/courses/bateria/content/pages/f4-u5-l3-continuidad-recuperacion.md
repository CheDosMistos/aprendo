## Objetivo

Pasar de demostrar un compás aislado a mantener una frase breve con continuidad razonable.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — GROOVE BASE A · 4 COMPASES

<div data-notation-score data-score-src="/bateria/notation/f4/u5/f4-u5-l3-groove-base-a-4bars.musicxml" data-score-title="Unidad 5.Lección 3 — Groove Base A · 4 compases" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

La partitura repite el mismo Groove Base A durante cuatro compases. **No hay variaciones**.

La dificultad nueva es sostener función y tiempo, no recordar material nuevo.

## Dos modos de práctica

### Laboratorio

- detén la tarea sólo si aparece un fallo recurrente;
- localiza la transición;
- aplica un correctivo breve;
- recompón la frase.

### Interpretación

- toca los cuatro compases sin detenerte por un error aislado;
- mantén o recupera el pulso;
- revisa después.

## Recuperarse no es ocultar el error

Si falla una nota:

1. no intentes “pagarla” añadiendo otra fuera de lugar;
2. conserva la subdivisión interna;
3. busca la siguiente referencia clara;
4. vuelve al patrón previsto;
5. analiza el fallo después de terminar la frase.

## Qué observar

`CONTINUIDAD / PULSO / FORMA / RECUPERACIÓN / SONIDO / TENSIÓN`

Un intento con una nota incorrecta pero pulso y forma conservados puede ser más útil que un intento “perfecto” que sólo funciona reiniciando cada vez.

## MÍNIMO PARA AVANZAR

- completas una frase de cuatro compases;
- un error aislado no obliga siempre a parar;
- recuperas una referencia clara cuando es posible;
- distingues modo laboratorio de modo interpretación;
- registras qué capa o transición produce los fallos recurrentes.

## Registrar esta práctica

Anota `frase → error → continuidad sí/no → recuperación → diagnóstico posterior`.
