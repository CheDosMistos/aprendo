## Objetivo

Convertir el desplazamiento en una operación que puedas **predecir y representar**, no sólo imitar.

## Tres preguntas antes de tocar

Para cualquier ejercicio de U2 identifica:

1. **qué material se mantiene**;
2. **cuál es la cuadrícula de referencia**;
3. **cuánto y hacia dónde se desplaza**.

Si no puedes responder esas tres preguntas, es fácil confundir desplazamiento con transformación o con un cambio de métrica.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — C: coordenadas rítmicas

Parte de una célula de corcheas o semicorcheas que ya puedas tocar cómodamente.

Escribe cuatro versiones:

- posición original;
- `+1` unidad de subdivisión;
- `+2` unidades;
- `+3` unidades.

Para cada versión anota debajo la cuadrícula completa del compás.

### Validación

- el compás permanece constante;
- la subdivisión permanece constante;
- la célula mantiene sus distancias internas;
- sólo cambia su posición;
- si una versión rebasa la barra, no la uses todavía: rediseña el ejemplo para mantenerlo dentro de U2.

## Predecir antes de escuchar

Antes de tocar cada versión:

1. marca el `1`;
2. señala verbalmente dónde empezará la célula;
3. imagina o canta la entrada;
4. toca;
5. compara la predicción con el resultado.

La predicción es importante porque separa comprensión de ensayo y error motor.

## Lectura inversa

Pide a otra persona, o usa tus propias tarjetas después de dejarlas reposar, que te presente una versión desplazada sin indicar el offset.

Debes identificar:

- punto de inicio;
- distancia respecto a la posición original;
- si la forma interna se ha conservado.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — D: detectar el falso desplazamiento

Escribe tres ejemplos:

- uno con desplazamiento real;
- uno donde cambie la célula pero no su posición;
- uno donde cambien ambas cosas.

Después clasifícalos sin tocar primero.

El objetivo es reforzar terminología y diagnóstico, no crear una taxonomía abstracta desconectada del sonido.

## Recuperación

Si pierdes la referencia:

`pulso → cuadrícula → punto de inicio → célula`

No intentes reconstruir primero la célula completa si ya no sabes dónde está el `1`.

## Criterio de avance

Puedes escribir varias posiciones de una misma célula, prever dónde comienza cada una y reconocer cuándo un ejemplo deja de ser un desplazamiento puro porque también ha cambiado el material.
