## Objetivo

Comprobar que Fase 1 no se ha convertido en una lista de rudimentos: leer material nuevo, escuchar antes de ver y crear una idea breve con recursos ya disponibles.

## 1. Lectura nueva en 4/4 — 7 min

`EJERCICIO ORIGINAL CREADO PARA ESTE CURSO`

<div data-notation-score data-score-src="/bateria/notation/u10/lectura-cierre-4-4.musicxml" data-score-title="Lectura nueva de cierre — 4/4" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

Usa el ciclo:

`VER → CONTAR → CANTAR → TOCAR → ESCUCHAR`

No memorices la línea antes de tocarla. Si falla, identifica si el problema es figura/silencio, subdivisión, pulso o ejecución.

## 2. Lectura nueva en 6/8 — 5 min

`EJERCICIO ORIGINAL CREADO PARA ESTE CURSO`

<div data-notation-score data-score-src="/bateria/notation/u10/lectura-cierre-6-8.musicxml" data-score-title="Lectura nueva de cierre — 6/8" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

Esta tarea recupera una exposición anterior. No pretende convertir 6/8 en competencia funcional de salida.

## 3. Oído antes de ver — 5 min

Escucha e imita la célula sin mirar primero una respuesta escrita:

<div data-rhythm-dictation data-bpm="66" data-subdivision="2" data-pattern="10110100" data-answer="Rejilla de corcheas: X · X X · X · ·"></div>

Después escribe o describe la célula. Se evalúa la cadena `escuchar → retener → representar`, no la velocidad.

## 4. Microcomposición — 7 min

`EJERCICIO ORIGINAL CREADO PARA ESTE CURSO`

<div data-notation-score data-score-src="/bateria/notation/u10/semilla-microcomposicion.musicxml" data-score-title="Semilla para microcomposición" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

Crea una pieza de **2–4 compases** partiendo de la semilla o de una célula propia. Cambia deliberadamente una o dos variables:

- densidad;
- acento;
- sticking;
- inicio;
- agrupación accesible;
- dinámica.

Debes poder explicar qué conservaste y qué transformaste.

## 5. Registro — 3 min

Anota por separado:

- qué parte de la lectura fue realmente nueva;
- qué pudiste reconstruir por oído;
- qué transformación creativa realizaste;
- qué competencia debería ganar peso en Fase 2.

## Criterio de avance

Puedes pasar a L4 si has producido evidencia de lectura no memorizada, una tarea auditiva y una transformación creativa básica. Ninguna de ellas se convierte en un segundo examen independiente del hito PAS.
