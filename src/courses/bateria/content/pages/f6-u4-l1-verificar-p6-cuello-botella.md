## Objetivo

Comprobar la **la puerta de entrada de la fase** y diagnosticar qué limita una tarea de independencia antes de añadir complejidad.

puerta de entrada exige:

- coordinación básica de cuatro extremidades FUNCIONAL;
- subdivisión binaria y ternaria FUNCIONAL;
- ostinato básico mantenido sin colapso de tiempo.

## 1. Prueba la capa base sola

Elige una función musical sencilla ya conocida y mantenla sin añadir voz variable.

Evalúa por separado:

- pulso;
- subdivisión;
- sonido;
- relajación;
- consistencia de la capa.

Si la base ya es inestable, el problema todavía no es «independencia avanzada».

## 2. Prueba la voz variable sola

Ejecuta la segunda capa de manera aislada.

Si no puedes representarla, contarla o tocarla por sí misma, combinarla sólo ocultará el cuello de botella.

## 3. Combina con la menor variación útil

Añade una única variación sobre la capa estable.

Observa qué cambia primero:

- se altera el pulso;
- desaparece la capa base;
- la voz variable se deforma;
- aparece tensión;
- cambia involuntariamente la dinámica;
- pierdes la posición dentro del ciclo.

Ese primer cambio ofrece una pista diagnóstica.

## 4. Clasifica el cuello de botella

### TEMPORAL
No se mantiene la subdivisión o la referencia interna.

### MOTOR
La combinación física concreta todavía no está disponible con control.

### DE REPRESENTACIÓN
No sabes con suficiente claridad qué debe ocurrir simultáneamente.

### ATENCIONAL
Ambas capas funcionan aisladas, pero la atención no se distribuye todavía de forma estable.

### DE SONIDO/TENSIÓN
La combinación sale, pero con rigidez, golpes accidentales o dinámica no intencional.

Las categorías pueden solaparse; sirven para elegir el siguiente experimento, no como diagnóstico clínico.

## Ejercicio original creado para este curso

Usa una capa base sencilla y una voz variable de 1–2 eventos por ciclo.

Haz cuatro pruebas:

1. base sola;
2. variable sola;
3. combinación;
4. combinación reducida a la mitad de variaciones.

Registra:

`QUÉ FALLA PRIMERO → HIPÓTESIS → REDUCCIÓN → RESULTADO`

## Ruta si puerta de entrada no está abierta

No avances por fuerza. Trabaja temporalmente:

- capa base más simple;
- voz variable menos densa;
- ciclos más cortos;
- conteo/canto previo;
- recombinación inmediata.

Después vuelve a comprobar puerta de entrada.

## MÍNIMO PARA AVANZAR

- la capa base es temporalmente fiable;
- la voz variable existe por separado;
- puedes identificar el primer punto de ruptura al combinarlas;
- eliges una reducción relacionada con el problema;
- no llamas «falta de independencia» a cualquier error inespecífico;
- puerta de entrada está abierta para la ruta principal o sigues conscientemente la ruta de consolidación.
