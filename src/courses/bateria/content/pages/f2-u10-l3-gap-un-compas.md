El gap introduce una ausencia temporal completa de referencia externa durante un compás.

## Protocolo

1. confirma que la línea funciona con referencia completa;
2. mantén BPM y sticking;
3. selecciona `Gap · 1 compás sí / 1 no · 4/4`;
4. durante el compás silencioso sigue sintiendo cuatro pulsos y su subdivisión;
5. no ajustes conscientemente el último pulso para “atrapar” el click;
6. observa el reencuentro cuando reaparece la referencia.

## El reencuentro es evidencia

No midas sólo si “caes encima”. Registra también **cómo** llegas:

- reaparece el click sin corrección brusca;
- llegas antes y debes frenar;
- llegas después y debes acelerar;
- mantienes continuidad aunque exista un pequeño desfase;
- pierdes la estructura del compás silencioso.

Un pequeño error recuperado aporta información distinta de un colapso completo.

## Control de dificultad

Si el gap destruye pulso interno/subdivisión binaria y ternaria:

`GAP → HALF-TIME O CLICK COMPLETO → CORRECTIVO → RETEST`.

Eso no degrada automáticamente tu estado de competencia.

## MÍNIMO PARA AVANZAR

Puedes pasar a Lección 4 cuando el gap produzca una muestra interpretable: estabilidad razonable o, si falla, una variable limitante localizada y repetible.
