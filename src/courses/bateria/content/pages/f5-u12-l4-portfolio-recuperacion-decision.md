## Objetivo

Convertir tres piezas en un **portfolio de evidencia** que permita decidir qué está suficientemente funcional y qué necesita mantenimiento.

> **PORTFOLIO ≠ MEDIA NUMÉRICA DE TRES TOMAS.**

El Hito 6 no se resuelve sumando puntos. Se observa si la función musical superior está presente en varias piezas y dónde aparece una limitación crítica.

## 1. Reúne sólo evidencia interpretable

Incluye para A, B y C:

- una toma principal;
- condiciones y ayudas declaradas;
- simplificaciones conscientes;
- una breve nota de recuperación ante errores;
- la dimensión crítica de esa pieza;
- un correctivo aplicado o previsto.

No elijas únicamente “la mejor toma” si eso oculta el proceso.

## 2. Matriz de comparación

Usa esta matriz cualitativa:

| Dimensión | Pieza A | Pieza B | Pieza C |
|---|---|---|---|
| estructura | | | |
| tiempo/pulso | | | |
| groove/feel | | | |
| dinámica | | | |
| fills/transiciones | | | |
| recuperación | | | |
| sonido/balance | | | |
| fuentes/ayudas | | | |
| condiciones declaradas | | | |
| escucha segura/carga | | | |

No hace falta convertir las celdas en números.

## 3. Busca el patrón, no el accidente

Distingue:

- **error local:** aparece una vez y la música se recupera;
- **problema de pieza:** reaparece en una sección concreta de una sola pieza;
- **problema transversal:** aparece en varias piezas y limita la misma función.

Ejemplo:

- A: el fill compromete el retorno;
- B: otro fill compromete el retorno;
- C: la transición se recupera bien.

La dimensión crítica puede ser **H6 retorno tras fill**, no “tocar peor en general”.

## 4. No promedies una debilidad crítica

Dos piezas muy sólidas no convierten automáticamente en funcional una tercera pieza cuya forma se pierde sistemáticamente.

Pero una pieza con un error local tampoco invalida automáticamente las otras dos.

> **UNA DEBILIDAD CRÍTICA SE DIAGNOSTICA; NO SE ESCONDE EN UNA MEDIA NI BORRA TODO EL PROGRESO.**

## 5. Correctivo transversal

Cuando detectes una dimensión recurrente, usa:

`síntoma → hipótesis → prueba → correctivo → recomposición`.

Después prueba el correctivo primero en la pieza donde el problema sea más claro y, si procede, comprueba transferencia a otra.

Ejemplo:

`síntoma: pierdo el 1 tras fills → hipótesis: el fill no está anclado a la frase → prueba: fill de un tiempo → correctivo: reducir densidad + cantar el 1 → recomposición: 4 compases groove + fill + 4 compases groove`.

## 6. Cuatro decisiones posibles

### AVANZAR
El núcleo del Hito 6 aparece de forma suficientemente estable en A/B/C y las debilidades restantes son mantenimiento razonable.

### MANTENER
El hito está cerca, pero una dimensión necesita más evidencia retenida antes de cerrar la fase.

### CORREGIR
Existe una limitación concreta y diagnosticable que impide observar estructura, tiempo, dinámica o recuperación en una o más piezas.

### REDUCIR CARGA
La fatiga física/auditiva o la densidad de sesión está degradando la evidencia. Reduce exposición, densidad o duración antes de interpretar el resultado como falta de competencia.

## 7. Qué NO hacer

No:

- repitas toda Fase 5 por un fill problemático;
- añadas complejidad para “demostrar nivel”;
- cambies de repertorio sólo porque una toma salió mal;
- fuerces tres piezas en una sesión si la carga empeora la calidad;
- ocultes ayudas o simplificaciones;
- sustituyas recuperación musical por reinicios sistemáticos.

## 8. Preparación del Hito 6

Antes del checkpoint final debes poder responder:

1. ¿qué evidencia tengo de cada pieza?;
2. ¿qué ayudas estaban presentes?;
3. ¿qué error relevante apareció y cómo se recuperó?;
4. ¿qué dimensión es la más débil del portfolio?;
5. ¿qué correctivo la aborda?;
6. ¿la evidencia representa una competencia disponible más allá de una única toma favorable?;
7. ¿la carga de sesión fue razonable?

## Criterio de avance

Avanza al checkpoint cuando el portfolio permite una decisión argumentada sin depender de promedios, perfección ni complejidad artificial.

**No existe BPM de aprobado.**
