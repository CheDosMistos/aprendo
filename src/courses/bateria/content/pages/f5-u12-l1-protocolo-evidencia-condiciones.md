## Objetivo

Convertir cada interpretación de A, B o C en una evidencia **interpretable**, no en una toma aislada sin contexto.

> **EVIDENCIA SIN CONDICIONES DECLARADAS = EVIDENCIA DIFÍCIL DE INTERPRETAR.**

El objetivo no es uniformar todas las ayudas, sino saber **qué estaba disponible** en cada toma.

## 1. Ficha mínima por pieza

Antes de tocar, registra:

- pieza: A / B / C;
- fecha o identificador de toma;
- ruta principal: chart / escucha / híbrida;
- ayudas disponibles: chart, playback, click, cues, mapa formal;
- simplificaciones deliberadas;
- versión de groove o feel elegida;
- condición de grabación;
- carga aproximada de sesión;
- protección auditiva y pausas cuando proceda.

Las ayudas no invalidan automáticamente la evidencia. **Ocultarlas sí impide juzgarla con precisión.**

## 2. Cadena de registro

Usa siempre:

`PIEZA → CONDICIONES → EVIDENCIA → DIMENSIÓN CRÍTICA → RECUPERACIÓN → DECISIÓN`

No necesitas una puntuación media de diez apartados.

La pregunta es qué dimensión limita más la función musical en esa pieza.

## 3. Condiciones comparables, no idénticas

Pieza A puede necesitar chart; Pieza B puede depender más de escucha; Pieza C combina fuentes.

No fuerces condiciones idénticas sólo para aparentar objetividad.

Compara de forma razonable:

- una toma A con otra toma A bajo ayudas equivalentes;
- una toma B con otra B bajo referencia auditiva equivalente;
- una toma C con otra C declarando qué fuentes siguen disponibles.

> **COMPARABLE ≠ IDÉNTICO.**

## 4. Qué registrar durante la toma

No interrumpas la música para tomar notas.

Después de tocar, anota brevemente:

- ¿se mantuvo la forma?;
- ¿el pulso sobrevivió a transiciones y errores?;
- ¿la dinámica distinguió las secciones necesarias?;
- ¿los fills ayudaron o estorbaron al retorno?;
- ¿hubo una recuperación funcional?;
- ¿el sonido/balance permitió entender las capas principales?;
- ¿qué ayuda fue realmente necesaria?

## 5. Una toma favorable no basta

Una toma puede salir especialmente bien por azar, concentración puntual o condiciones favorables.

Por eso la evidencia final debe apoyarse en más de un intento cuando sea razonable y, sobre todo, en una representación que pueda **recuperarse después de una pausa, otra tarea o una sesión posterior**.

> **RETENCIÓN ≠ REPETICIÓN INMEDIATA.**

No necesitas repetir las tres piezas muchas veces en una sola sesión.

## 6. K7 — carga auditiva y física

Las piezas completas acumulan más exposición que un ejercicio de pocos compases.

La regla práctica sigue siendo:

`CARGA AUDITIVA = NIVEL × DURACIÓN`

Por tanto:

- reduce duración cuando el nivel sea alto;
- introduce pausas;
- evita encadenar tomas completas innecesarias;
- usa protección auditiva adecuada cuando corresponda;
- detén o reduce carga si aparece dolor, fatiga anormal o pérdida de control.

No se fija un número universal de dB “seguro” para cualquier batería, sala o persona.

## 7. ESENCIAL AHORA — una ficha, no burocracia

Para cada pieza basta una ficha breve:

| Campo | Registro |
|---|---|
| pieza | A / B / C |
| ruta | chart / escucha / híbrida |
| ayudas | |
| simplificaciones | |
| dimensión crítica | |
| error principal | |
| recuperación | |
| siguiente decisión | |
| carga/pausas | |

El registro existe para tomar mejores decisiones, no para producir papeleo.

## Criterio de avance

Puedes explicar qué condiciones acompañan cada evidencia, distinguir una ayuda legítima de una dependencia no declarada y organizar la sesión sin perseguir tomas completas innecesarias.

**No existe BPM de aprobado ni media numérica obligatoria.**
