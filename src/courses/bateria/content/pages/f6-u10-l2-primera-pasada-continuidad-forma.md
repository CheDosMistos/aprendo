## Objetivo

Obtener una **línea base de interpretación completa**.

En modo interpretación:

`EMPEZAR → SOSTENER → RECUPERAR → TERMINAR → ANALIZAR DESPUÉS`

Esto no sustituye el modo laboratorio del sistema de práctica.

## Error local vs colapso estructural

### Error local

Puede haber una nota, fill, articulación o dinámica defectuosa, pero todavía sabes:

- dónde está el pulso;
- en qué sección estás;
- qué viene después.

**Respuesta durante la pasada:** simplificar, recuperar función y continuar.

### Pérdida estructural

Has perdido la referencia suficiente para que ya no sabes de forma fiable dónde está la música.

**Respuesta posible:** buscar el siguiente landmark, usar el chart y reentrar. Si no es viable, termina la evidencia de esa pasada y analiza después.

No conviertas «nunca parar» en dogma. El sistema del curso distingue:

- **modo interpretación:** proteger continuidad y forma;
- **modo laboratorio:** detener, diagnosticar y corregir.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — «Pasada cero de intervención»

1. Prepara el chart.
2. Elige un contexto temporal/musical que no añada dificultad innecesaria.
3. Inicia la forma completa.
4. No detengas la pasada por un error local.
5. Si aparece sobrecarga, aplica la simplificación prevista en Lección 1.
6. Usa landmarks para recuperar posición.
7. Termina la forma.
8. Sólo entonces registra problemas.

## Qué registrar

No intentes escribir todo.

Selecciona evidencia sobre:

- continuidad;
- estabilidad temporal/subdivisión;
- forma;
- navegación funcional del chart;
- recuperación;
- dinámica/sonido;
- adecuación estilística;
- feel;
- uno o dos puntos de sobrecarga relevantes.

**No promedies estas dimensiones como una nota.**

## Grabación

Graba la pasada sólo si vas a usarla para responder una pregunta concreta.

Ejemplos:

- «¿perdí realmente tiempo en la transición B→C o sólo tuve esa sensación?»
- «¿mi reducción de densidad conservó el carácter?»
- «¿el retorno a A recuperó el centro dinámico?»

No conviertas la waveform o la rejilla de una DAW en juez de musicalidad.

## Error recovery intencional

Unidad 3 ya enseñó recuperación. esta unidad la aplica en continuidad extensa.

**EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — «Fallo local autorizado»**

En una segunda mini-pasada o ensayo parcial, introduce deliberadamente **un** fallo controlado:

- omite un fill previsto;
- entra con una textura más simple;
- ignora un detalle no crítico.

Comprueba si puedes conservar:

`PULSO → FORMA → SIGUIENTE LANDMARK → FUNCIÓN`

No introduzcas un error peligroso ni una coordinación que pueda provocar lesión.

## Rutinas

**MÍNIMA:** una pasada completa + una observación prioritaria.

**ESTÁNDAR:** pasada completa + revisión breve + un ensayo controlado de recuperación.

**AMPLIADA:** segunda pasada después de descanso suficiente, sin corregir todos los detalles entre medias, para comprobar qué problemas reaparecen.

## Criterio de salida

Continúa cuando dispones de una línea base suficientemente interpretable para responder:

- qué se mantuvo;
- dónde aumentó la carga;
- qué error fue local;
- si hubo pérdida estructural;
- qué problema merece intervención antes de la siguiente pasada.

> **LA PRIMERA PASADA NO ES UN EXAMEN: ES EL PRIMER DATO DEL PROYECTO.**
