## Objetivo

Colocar la Variación B en un punto formal fijo y demostrar el retorno a Groove A.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — FRASE A–A–B–A

<div data-notation-score data-score-src="/bateria/notation/f4/u7/f4-u7-l3-aaba-phrase.musicxml" data-score-title="40.U7.L3 — Frase A–A–B–A" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

La frase tiene cuatro compases:

1. **A** — Groove A;
2. **A** — Groove A;
3. **B** — añade bombo en `& de 3`;
4. **A** — retorno explícito al groove base.

La variación no es el destino. La habilidad completa es:

> **GROOVE → VARIACIÓN → RETORNO**

## Modo interpretación

1. Toca los cuatro compases completos.
2. No detengas la frase por un error aislado.
3. Si B falla, intenta conservar la rejilla y aterrizar en el tiempo 1 del compás 4.
4. Termina la frase y revisa después.

## Modo laboratorio

Aísla una transición sólo si el diagnóstico lo justifica:

- `A → B` si anticipas el golpe nuevo;
- `B → A` si arrastras la variación al compás 4.

Después de pocas repeticiones, **recompón A–A–B–A inmediatamente**.

## Qué observar

`FORMA / PULSO / SUBDIVISIÓN / VARIACIÓN / RETORNO / BALANCE / RECUPERACIÓN`

Un B técnicamente correcto que desplaza el compás 4 no cumple el objetivo.

## MÍNIMO PARA AVANZAR

- sabes en qué compás aparece B;
- mantienes una frase de cuatro compases reconocible;
- la variación conserva el pulso;
- vuelves a A en el cuarto compás;
- puedes recuperar una referencia clara tras un error;
- diferencias laboratorio de interpretación.

## Registrar esta práctica

Anota `A–A–B–A → transición frágil → correctivo → frase completa`.
