## Objetivo

Aplicar el procedimiento de esta unidad a un motivo rítmico propio ya creado antes de la llegada del kit.

No aparece aquí una partitura fija porque **tu motivo es el material fuente**. Inventar uno nuevo y presentarlo como tu composición anterior rompería la continuidad del curso.

## Protocolo de transferencia

### 1. Recupera la versión base

Toca el motivo en una sola superficie y confirma:

- duración;
- subdivisión;
- acentos;
- sticking real;
- forma breve.

### 2. Elige una intención tímbrica

Selecciona **1–2 ataques** como máximo para la primera versión orquestada.

Pregúntate qué quieres conseguir:

- contraste;
- dirección;
- respuesta;
- separación de una frase;
- refuerzo de una jerarquía ya existente.

### 3. Mueve sólo esas notas

No cambies a la vez duración, densidad, subdivisión y sticking.

Toca:

`VERSIÓN BASE → VERSIÓN ORQUESTADA → VERSIÓN BASE`

Si la identidad desaparece, reduce el recorrido.

### 4. Añade pies conocidos

Sólo cuando las manos sean estables:

- bombo 1 y 3;
- chick de hi-hat 2 y 4.

Los pies son una base, no una nueva composición.

### 5. Revisa el sticking

Consérvalo si funciona. Si una ruta física hace que una mano quede atrapada o que la nota siguiente llegue tarde, prueba una alternativa y registra:

`PROBLEMA → STICKING ORIGINAL → CAMBIO → RESULTADO`.

### 6. Graba o escucha una toma

Compara:

`IDENTIDAD / PULSO / TIMBRE / MOVIMIENTO / BALANCE / INTENCIÓN`.

## Si tu motivo necesita refuerzo

No inventes otro para “pasar” la lección. Puedes practicar el protocolo con la frase Unidad 2 de tres superficies y volver a tu motivo cuando esté recuperado.

Eso no convierte el material Unidad 2 en una composición tuya.

## MÍNIMO PARA AVANZAR

- recuperas un motivo propio o identificas correctamente que necesita refuerzo;
- produces una versión base y otra orquestada con cambios limitados;
- conservas una identidad rítmica reconocible;
- añades la base de pies sólo cuando procede;
- explicas al menos una decisión de superficie;
- si cambias sticking, lo haces deliberadamente;
- grabas/escuchas y seleccionas una prioridad real.

## Frontera

Una orquestación puede sonar a frase o transición, pero **esta unidad no la certifica como fill fills**. Tampoco entrena independencia sistemática avanzada.

## Registrar esta práctica

Anota `motivo → intención → superficies → sticking → resultado → siguiente ajuste`.
