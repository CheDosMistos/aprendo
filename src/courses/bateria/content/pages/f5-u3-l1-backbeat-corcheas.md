## Objetivo

Construir y sostener el groove CORE sin fills, observando cómo se relacionan sus capas.

## Qué contiene

- hi-hat cerrado: corcheas continuas;
- caja: 2 y 4;
- bombo: 1 y 3;
- dos compases idénticos para observar continuidad.

Esto es un **arquetipo pedagógico de entrada**. No significa que todo rock o pop use exactamente este patrón.

## Construcción por capas

1. hi-hat solo;
2. hi-hat + caja;
3. hi-hat + bombo;
4. groove completo;
5. dos compases completos sin añadir fill.

Si una combinación falla, reduce una capa y vuelve a recomponer pronto.

## Escucha interna

No preguntes sólo “¿cayeron las notas?”. Escucha:

- ¿el backbeat se percibe claro?;
- ¿el hi-hat mantiene una referencia estable?;
- ¿bombo y caja desorganizan o refuerzan el pulso?;
- ¿el volumen entre capas permite entender el groove?;
- ¿aparece tensión innecesaria?

## Aplicación a forma

Toca 4 compases y cuenta una frase simple:

`1 2 3 4 | 2 2 3 4 | 3 2 3 4 | 4 2 3 4`.

El objetivo es que groove y forma existan a la vez.

## Fuente pedagógica

Vic Firth / Stanton Moore documenta una categoría pedagógica de **8th note rock beats** usada en muchas canciones populares. Berklee/Larry Finn recomienda aprender beats separando capas y recomponiéndolas. Estas referencias apoyan el punto de entrada; **no convierten el ejercicio en un estándar universal de rock**.

- Vic Firth: https://ae.vicfirth.com/education/beginner-drumset-lessons/beginner-drum-set-lessons-11/
- Berklee Online: https://online.berklee.edu/takenote/basic-funk-for-drums/

## MÍNIMO PARA AVANZAR

- sostienes el groove CORE durante varios compases razonables para tu condición;
- caja 2/4 y referencia de corcheas permanecen reconocibles;
- puedes separar y recomponer capas;
- conservas forma de 4 compases;
- explicas por qué este groove no define por sí solo un estilo completo;
- mantienes relajación, carga y escucha seguras.

**No existe BPM de aprobado.**

## Registrar esta práctica

Registra `capa más inestable / balance / tensión / continuidad / correctivo`.
