## Objetivo

Usar una preparación breve para reducir los errores que más amenazan la continuidad musical.

La tarea no es «estudiar rápido todo». Es asignar un **presupuesto de atención**.

## 1. Prioriza por coste musical del error

Antes de practicar una zona, pregunta:

- si fallo aquí, ¿pierdo la forma?;
- ¿entro tarde o dejo solo al grupo?;
- ¿rompo un corte importante?;
- ¿puedo simplificar sin dañar la función?;
- ¿puedo recuperarme en el siguiente punto estructural?

Una figure técnicamente difícil puede ser menos prioritaria que una entrada sencilla pero estructural.

## 2. Usa una matriz sencilla

Clasifica cada zona relevante:

`IMPACTO ALTO / BAJO × INCERTIDUMBRE ALTA / BAJA`

Trabaja primero los casos de **impacto alto + incertidumbre alta**.

Esta matriz es una herramienta de decisión del curso, no una escala científica universal.

## 3. Decide qué preparar y qué aplazar

Tu preparación puede incluir:

- contar una transición;
- cantar una figure;
- tocar sólo el ritmo de un cue;
- marcar una reentrada;
- decidir una versión simplificada;
- aclarar una repetición;
- comprobar una dinámica relativa.

No conviertas la preparación en una interpretación completa anticipada.

## 4. Establece una versión de seguridad

Para una zona que todavía no controlas, define qué harás si no puedes ejecutar el detalle:

`MANTENER TIEMPO → CONSERVAR FORMA → RESPONDER AL EVENTO PRINCIPAL → OMITIR DETALLE`

La versión de seguridad debe ser musicalmente compatible, no una excusa para evitar aprender.

## 5. Haz una pasada y revisa la predicción

Después de tocar, compara:

- riesgo previsto;
- error real;
- impacto real;
- estrategia elegida.

Si preparaste mucho una zona que no causó problemas y falló otra estructural, actualiza tu diagnóstico.

## Ejercicio original creado para este curso

Con un chart de U3:

1. elige cinco eventos visibles;
2. clasifícalos por impacto e incertidumbre;
3. prepara sólo los dos prioritarios;
4. define una versión de seguridad para uno;
5. realiza una pasada continua;
6. registra si tu priorización fue correcta.

## Errores frecuentes

- gastar todo el tiempo previo en el pasaje técnicamente más vistoso;
- no preparar una reentrada tras un silencio;
- intentar resolver cinco problemas a la vez;
- tratar una simplificación como versión definitiva;
- no revisar si la predicción de riesgo era correcta.

## MÍNIMO PARA AVANZAR

- identificas qué errores tendrían mayor coste musical;
- seleccionas una preparación proporcional al riesgo;
- defines al menos una versión de seguridad razonable;
- realizas una pasada continua;
- comparas riesgo previsto y problema real;
- ajustas la siguiente preparación según evidencia.

**No existe BPM de aprobado.**
