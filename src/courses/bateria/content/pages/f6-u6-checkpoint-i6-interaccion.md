## Qué se intenta demostrar

El criterio superior de interacción y ensemble en nivel **MÍNIMO PARA AVANZAR** es:

> **Atiende a bajo, forma y señales básicas.**

En esta unidad se operacionaliza sin crear una rúbrica paralela:

> ante información musical externa, detecta una señal relevante, comprende suficientemente su función, modifica al menos una decisión de ejecución y mantiene continuidad temporal/formal suficiente.

Completar la página no demuestra automáticamente la competencia. La decisión se basa en evidencia observable.

## Tarea A — Bajo + forma

**EJERCICIO ORIGINAL CREADO PARA ESTE CURSO.**

Usa una pista/stem legal u original con bajo claramente audible y al menos dos secciones contrastantes.

1. Antes de tocar, identifica pulso y forma aproximada.
2. Durante una toma continua, conserva una versión base estable.
3. Selecciona **un cambio del bajo o del arreglo** y modifica una sola dimensión: densidad, dinámica, articulación, orquestación o refuerzo selectivo.
4. Continúa la forma después de la respuesta.

Evidencia mínima: puedes señalar `QUÉ CAMBIÓ → QUÉ HICISTE → POR QUÉ`.

## Tarea B — Cue + continuidad

Usa una estructura original con al menos tres clases de evento, por ejemplo:

- entrada/reentrada;
- corte/stop;
- cambio dinámico;
- figure;
- transición;
- ending.

La prueba no requiere respuesta espectacular. Sí requiere que la señal produzca una decisión compatible y que la música continúe.

## Tarea C — Información parcial / call-response

Usa una variante no memorizada donde una capa desaparezca/reaparezca o aparezcan llamadas breves pregrabadas.

Demuestra:

- memoria temporal suficiente durante la ausencia;
- reentrada sin reconstruir desde cero;
- una respuesta que no sea siempre imitación;
- continuidad de forma.

## Tarea D — Interacción real, cuando sea posible

Si tienes acceso a otro músico, realiza una toma breve con cambios no pactados nota por nota. Después registra:

1. una acción del compañero que cambió tu ejecución;
2. tu respuesta;
3. si tu respuesta influyó en una acción posterior del compañero.

Esta tarea aporta evidencia de reciprocidad. **No es requisito material obligatorio para avanzar**.

Si no existe compañero, registra:

`INTERACCIÓN INTERPERSONAL REAL: NO OBSERVADA TODAVÍA`.

No se infiere desde una pista fija.

## Dimensiones críticas observables

Compatible con `06_SISTEMA_PRACTICA_Y_EVALUACION`:

- **tiempo/subdivisión:** la atención externa no destruye la referencia;
- **exactitud/forma:** responde en el lugar funcional y continúa;
- **dinámica/sonido:** cuando son parte de la decisión, el cambio es intencional;
- **comprensión:** explica señal, función y respuesta;
- **transferencia:** responde a más de una clase de información o en una variante no memorizada;
- **recuperación:** un error pequeño no obliga a detener la interpretación.

No se promedian estas dimensiones como nota numérica.

## MÍNIMO PARA AVANZAR — interacción y ensemble

Existe evidencia suficiente cuando, en tareas adecuadas:

- atiendes a bajo, forma y al menos una clase de señal básica;
- una información externa produce una modificación audible/observable de tu ejecución;
- la respuesta es funcional aunque sea sencilla;
- mantienes continuidad suficiente después del evento;
- puedes explicar qué información utilizaste;
- distingues claramente una pista fija de interacción interpersonal bidireccional.

Con pistas fijas variadas y bien diseñadas, esto puede certificar **interacción y ensemble MÍNIMO robusto** y componentes funcionales observables.

## COMPETENTE / FUNCIONAL — evidencia orientativa

Sin sustituir el criterio textual del mapa, busca progresivamente:

- respuestas consistentes a varias clases de información;
- decisiones adecuadas de tiempo, forma, densidad, dinámica o fraseo;
- menor dependencia de recordar el orden de eventos;
- transferencia entre distintas pistas/situaciones;
- cuando exista interacción real, adaptación a acciones de otros músicos.

Una pista fija puede sostener varios componentes de este perfil, pero **no basta para afirmar interacción interpersonal completa**.

## AVANZADO — evidencia orientativa

Requiere más flexibilidad, anticipación, sensibilidad contextual y, para la parte interpersonal, evidencia suficiente de interacción real:

- ajustes bidireccionales;
- liderazgo/seguimiento variable;
- negociación de cambios no predeterminados;
- recuperación compartida;
- adaptación sensible al contexto.

esta unidad no exige este nivel para continuar.

## Decisión

Usa el lenguaje aprobado:

- **CONTINUAR** — interacción y ensemble MÍNIMO está suficientemente demostrado;
- **CONTINUAR + CORRECTIVO** — existe una fragilidad localizada que no invalida el núcleo;
- **REDUCIR NOVEDAD** — la atención externa desorganiza de forma sistemática tiempo/forma o la señal no se convierte todavía en decisión;
- **DETENER CARGA** — sólo cuando corresponda por salud/carga según el sistema general.

## Fronteras de certificación

Este Evaluación:

- **no declara Hito 7**;
- no certifica dominio estilístico;
- no adelanta Unidad 7 como transferencia entre estilos;
- no convierte Unidad 8 en recetas de microtiming;
- no sustituye el proyecto sostenido de Unidad 10;
- no abre polirritmia profunda, polimetría o modulación métrica de Fase 7;
- no usa BPM universal de aprobado.

> **Evaluación = RESPUESTA FUNCIONAL OBSERVABLE A INFORMACIÓN EXTERNA + CONTINUIDAD.**
