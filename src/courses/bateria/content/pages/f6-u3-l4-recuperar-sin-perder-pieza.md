## Objetivo

Practicar una habilidad que no se aprende evitando todos los errores: **recuperarse mientras la música continúa**.

La secuencia de seguridad es:

`DETECTAR PÉRDIDA → SIMPLIFICAR → RECUPERAR PULSO → LOCALIZAR FORMA → REENTRAR → RECONSTRUIR DETALLE DESPUÉS`

## 1. Distingue error local de pérdida global

Un golpe incorrecto, una figure omitida o una lectura dudosa son errores locales.

Se convierten en pérdida global cuando provocan:

- detenerte;
- cambiar el pulso para corregir;
- saltar o añadir compases sin darte cuenta;
- perder la sección actual;
- perseguir el error mientras el arreglo sigue avanzando.

La primera intervención es impedir esa escalada.

## 2. Simplifica inmediatamente

Si una zona se rompe, vuelve a una referencia sostenible:

- capa de tiempo;
- groove esqueleto;
- negras;
- silencio deliberado si el arreglo lo permite;
- otra opción simple compatible con la música.

La simplificación es temporal. Su función es liberar atención para recuperar navegación.

## 3. Busca el siguiente punto fiable

No intentes reentrar en cualquier nota.

Busca una referencia que puedas reconocer con seguridad:

- inicio de sección;
- corte;
- cue inequívoco;
- repetición;
- cambio de dinámica/textura;
- final de frase.

## 4. Entrena errores deliberados

En una práctica controlada puedes simular:

- omitir una figure;
- perder voluntariamente una línea durante un compás;
- tapar parte del chart;
- comenzar desde un punto intermedio;
- reentrar tras un silencio no preparado.

**EJERCICIO ORIGINAL CREADO PARA ESTE CURSO.** El objetivo no es tocar peor: es crear oportunidades seguras para practicar recuperación.

## 5. Repara después de la pasada

Durante una pasada continua, prioriza continuidad.

Después:

1. localiza el error;
2. diagnostica su causa;
3. decide si necesita adquisición, estabilización o simplemente una mejor señal de navegación;
4. practica el fragmento;
5. vuelve a una pasada completa.

No conviertas el modo interpretación en una sucesión de paradas de laboratorio.

## Ejercicio original creado para este curso

Haz tres pasadas del mismo chart:

- **A:** normal;
- **B:** introduce deliberadamente una pérdida local acordada;
- **C:** vuelve a tocar sin error deliberado y aplica la estrategia de recuperación sólo si hace falta.

Registra:

`PÉRDIDA → RESPUESTA → PUNTO DE REENTRADA → TIEMPO HASTA RECUPERAR FORMA → CORRECTIVO POSTERIOR`

No uses el tiempo de recuperación como puntuación universal; úsalo para comparar tu propio proceso.

## Errores frecuentes

- volver atrás mentalmente mientras la música continúa;
- acelerar para «alcanzar» el punto correcto;
- detenerte a corregir una figure secundaria;
- no tener puntos de reentrada preparados;
- confundir recuperación con ocultar sistemáticamente una debilidad.

## MÍNIMO PARA AVANZAR

- detectas una pérdida local sin convertirla en parada automática;
- simplificas para conservar referencia;
- localizas un punto de reentrada fiable;
- recuperas forma sin acelerar artificialmente;
- reparas el problema después de la pasada;
- distingues continuidad de evitación del aprendizaje.

**No existe BPM de aprobado.**
