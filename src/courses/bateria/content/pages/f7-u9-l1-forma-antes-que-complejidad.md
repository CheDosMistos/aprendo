## Objetivo

Diseñar una idea avanzada desde su **función musical**, no desde el deseo de acumular dificultad.

Al terminar debes poder responder antes de tocar:

- ¿qué quiero que ocurra en la forma?;
- ¿qué referencia temporal debe sobrevivir?;
- ¿qué recurso será dominante?;
- ¿cómo sabré que la idea ha resuelto?;

## J9 no es “J1 + J2 + … + J8”

Una estructura puede ser plenamente J9 usando sólo dos recursos si están integrados con intención.

También puede no ser J9 aunque contenga cinco técnicas, si éstas aparecen como una lista sin relación formal.

Ejemplo:

- compases 1–4: frase estable;
- compases 5–7: ciclo trans-barra que aumenta tensión;
- compás 8: resolución clara.

Aquí J5 tiene una **función formal**. No está colocado sólo para demostrar que puedes hacerlo.

## Cuatro decisiones antes de tocar

### 1. Referencia

Escoge qué debe permanecer audible o sentible:

- negra;
- subdivisión;
- comienzo de frase;
- ciclo común;
- métrica principal;
- duración puente si habrá modulación.

### 2. Función

El recurso puede servir para:

- crear tensión;
- retrasar una resolución;
- transformar un motivo;
- producir contraste;
- cambiar densidad;
- ocultar temporalmente una referencia;
- preparar una nueva sección;
- volver a hacer evidente el `1`.

### 3. Recurso dominante

Escoge uno:

`J1 / J2 / J3 / J4 / J5 / J6 / J7 / J8`

No elijas todavía tres “por si acaso”.

### 4. Salida

Decide cómo termina la manipulación:

- vuelta al motivo original;
- acento conjunto;
- inicio de sección;
- silencio;
- cambio de dinámica;
- regreso a la métrica principal;
- vuelta al tempo original.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — A: tarjeta de diseño

Escribe cuatro líneas:

1. **FORMA:** `A A B A`, `4+4`, `3+3+2 compases`, etc.
2. **FUNCIÓN:** una frase breve: “crear tensión antes del regreso”.
3. **RECURSO:** uno de J1–J8.
4. **SALIDA:** “resolver en el 1 del compás 8”.

Después toca una versión mínima.

Si no puedes mantener la forma sin el recurso avanzado, simplifica primero la base.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — B: versión simple / versión compleja

Construye una frase de cuatro u ocho compases.

### Versión 1 — reducida

- pulso claro;
- motivo simple;
- forma inequívoca.

### Versión 2 — integrada

Modifica sólo una sección usando un recurso avanzado.

Después graba ambas.

### Diagnóstico

No preguntes sólo “¿cuál es más difícil?”.

Pregunta:

- ¿qué cambia perceptivamente?;
- ¿la versión compleja crea una función reconocible?;
- ¿el regreso se entiende?;
- ¿el tiempo empeora?;
- ¿he perdido el motivo original?;

## Complejidad útil vs. complejidad ornamental

No hay nada malo en explorar por curiosidad. **Laboratorio** y **resultado musical** son dos modos distintos.

En modo laboratorio puedes probar una combinación aunque todavía suene torpe.

En modo interpretación, el criterio cambia:

> **la estructura debe seguir siendo comprensible, recuperable y deliberada.**

## Terminología como control de calidad

Antes de integrar un recurso, nómbralo correctamente.

- acentos `3+3+2` dentro de 4/4 → J1;
- misma célula movida de posición → J2;
- 7/8 real → J3;
- cinco partes iguales dentro del pulso → J4;
- célula que continúa cruzando barras → J5;
- dos capas rítmicas simultáneas → J6;
- dos ciclos métricos simultáneos → J7;
- una duración se convierte en nueva unidad de pulso → J8.

Si no sabes qué fenómeno estás usando, vuelve a su unidad antes de integrarlo.

## Metrónomo

Primera pasada:

- click regular y explícito.

Segunda pasada, si la forma se mantiene:

- click menos frecuente o sólo en puntos estructurales ya dominados.

No retires el click para “hacerlo más avanzado” si eso impide diagnosticar la integración.

## Oído

Escucha la grabación sin mirar la partitura y marca:

1. comienzo de cada sección;
2. entrada del recurso avanzado;
3. momento de máxima tensión;
4. resolución.

Si sólo puedes localizar esos puntos porque recuerdas el plan, la forma todavía puede necesitar más contraste audible.

## Creatividad

Haz tres versiones del mismo diseño cambiando sólo la función:

- versión TENSIÓN;
- versión CONTRASTE;
- versión TRANSICIÓN.

Puedes usar el mismo recurso rítmico. La pregunta es si aprendes a **hacerlo significar cosas distintas**.

## Recuperación

Si pierdes el recurso avanzado:

`abandona detalle complejo → conserva pulso/forma → vuelve al motivo base → reentra sólo en el siguiente punto formal definido`

No intentes “compensar” añadiendo notas para recuperar el inventario perdido.

## Criterio de avance

Puedes diseñar una frase donde un recurso avanzado tenga una función declarada, mantener la forma, salir de él conscientemente y explicar qué aporta frente a la versión reducida.
