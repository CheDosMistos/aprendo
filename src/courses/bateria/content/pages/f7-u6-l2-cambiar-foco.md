## Objetivo

Mantener la misma relación `3:2` mientras cambias **qué capa ocupa el primer plano perceptivo**.

Esto convierte la coordinación inicial de L1 en una competencia más robusta: no basta con reproducir una secuencia combinada; debes poder reconocer y conservar las dos periodicidades.

## La relación no cambia cuando cambia tu atención

En `3:2`:

- la capa de 3 sigue repartiendo tres ataques iguales por ciclo;
- la capa de 2 sigue repartiendo dos;
- el ciclo común sigue teniendo la misma duración.

Lo único que cambia en esta lección es **qué información resaltas**.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — D: voz selectiva

Toca ambas capas con las manos.

1. Durante cuatro ciclos, canta sólo la capa 2.
2. Sin detenerte, durante cuatro ciclos canta sólo la capa 3.
3. Después canta sólo los puntos de coincidencia.
4. Repite empezando por la capa 3.

### Criterio

La mano que no estás cantando no debe colapsar ni copiar a la capa vocalizada.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — E: acento perceptivo

Mantén ambas capas a dinámica moderada.

- 4 ciclos: capa 2 más fuerte, capa 3 suave;
- 4 ciclos: igualdad dinámica;
- 4 ciclos: capa 3 más fuerte, capa 2 suave;
- 4 ciclos: igualdad dinámica.

La relación temporal debe ser idéntica en las cuatro condiciones.

### Qué entrena

No busca volumen. Busca comprobar si puedes cambiar jerarquía perceptiva sin cambiar el ratio.

## 3:2 y 2:3 como perspectivas

En muchos contextos la etiqueta puede escribirse atendiendo a cuál de las dos periodicidades se nombra primero. En este curso evitaremos convertir el orden de los números en una fuente de confusión.

Siempre declara:

- **qué capa tiene 3**;
- **qué capa tiene 2**;
- **qué duración comparten como ciclo**.

La descripción explícita es más importante que memorizar una convención aislada.

## Intercambiar manos

### EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — F

Bloque 1:
- derecha = 3;
- izquierda = 2.

Bloque 2:
- izquierda = 3;
- derecha = 2.

Bloque 3:
- alterna la asignación cada cuatro ciclos, con una pausa breve entre bloques si hace falta.

El objetivo es separar **relación rítmica** de **preferencia motora**.

## Retirar la rejilla común

La rejilla de seis ayudó a construir el patrón. Ahora reduce ayuda en este orden:

1. seis posiciones vocalizadas;
2. sólo comienzos de ciclo + una capa;
3. sólo una capa vocalizada;
4. ninguna vocalización externa;
5. comprobación posterior con la rejilla si aparece deriva.

No retires la rejilla como prueba de orgullo. Retírala cuando deje de ser necesaria para mantener la relación.

## Metrónomo y referencia

### Etapa 1

Click en negras, coincidiendo con la capa 2 del modelo.

### Etapa 2

Click sólo al comienzo del ciclo de dos negras.

### Etapa 3 — AMPLIACIÓN

Alterna bloques donde la referencia externa favorece perceptivamente una capa u otra mediante una pista o guía diseñada para ello. Si no dispones de esa referencia, no es obligatorio simularla.

## Oído: ¿sigo oyendo dos capas?

Graba una toma y prueba tres escuchas:

- escucha A: sigue sólo la capa 2;
- escucha B: sigue sólo la capa 3;
- escucha C: oye el conjunto y anticipa el siguiente punto de coincidencia.

Si una capa desaparece perceptivamente, vuelve a exagerarla dinámicamente durante pocos ciclos y después normaliza.

## Error frecuente: resolver todo mediante una frase memorizada

Los mnemónicos pueden ayudar a ordenar ataques, pero si sustituyen completamente a las dos periodicidades crean una dependencia.

### Prueba de transferencia

Cambia:

- manos;
- dinámica;
- timbre;
- capa vocalizada.

Si la relación sobrevive, probablemente ya no depende exclusivamente de una secuencia verbal fija.

## Recuperación

Si una capa se pierde:

1. **no detengas automáticamente la otra**;
2. conserva la capa que sigue estable;
3. localiza el próximo comienzo de ciclo;
4. reintroduce la capa perdida desde ese punto.

Después practica la recuperación inversa, usando la otra capa como salvavidas.

## Aplicación al kit

Ejemplos de transferencia:

- ride = 3 / caja = 2;
- hi-hat = 2 / tom = 3;
- pie = 2 / mano = 3 cuando la coordinación lo permita.

No añadas más capas hasta poder escuchar claramente ambas existentes.

## Criterio de avance

Puedes mantener `3:2` mientras cambias capa vocalizada, capa acentuada y asignación de manos; además, puedes perder deliberadamente una capa y reintroducirla usando la otra como referencia.
