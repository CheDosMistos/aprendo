## Objetivo

Usar una identidad motívica dentro de una estructura mínima: **establecer A, crear contraste B y hacer reconocible el retorno de A**.

El esquema de trabajo es:

`A → A → B → A`

Es un **andamiaje de esta tarea**, no una forma musical universal.

En el modelo, los compases 1, 2 y 4 son A. El compás 3 es B.

Escucha primero la frase completa y después contesta:

- ¿qué hace que A sea recuperable después de B?;
- ¿B contrasta por densidad, distribución o ambas?;
- ¿el contraste rompe el pulso o sólo cambia el contenido?;
- ¿el cuarto compás se percibe como retorno porque A ya fue establecido antes?

## 1. Establece A · 5–6 min

Usa tu motivo de Lección 1 o crea uno nuevo, pero fija una versión clara antes de continuar.

Toca:

`A → A`

La segunda aparición debe ser una **repetición deliberada**, no una aproximación variable por falta de control.

Si necesitas reducir densidad para repetirla, hazlo.

## 2. Crea B · 5–6 min

Ahora crea una idea contrastante.

Regla importante:

> **contraste no significa “más notas” ni “más difícil”.**

Puedes contrastar mediante más espacio, otro comienzo, otro cierre, una distribución distinta de ataques o una densidad diferente.

Registra una frase: **“B contrasta con A porque…”**

## 3. Vuelve a A · 5–6 min

Toca la frase completa:

`A → A → B → A`

Observa por separado:

- **identidad:** el último A sigue siendo reconocible;
- **memoria:** puedes recuperarlo después de B;
- **continuidad:** el marco temporal no se rompe mientras decides;
- **cierre:** el retorno ayuda a percibir una llegada, sin afirmar que todo cierre deba funcionar así.

## 4. Escríbela y grábala · 5–7 min

Escribe las cuatro unidades o compases. Después graba una toma.

Compara:

1. intención escrita;
2. ejecución real;
3. continuidad;
4. si B fue realmente contrastante;
5. si el retorno coincide con A o sufrió cambios accidentales.

No borres la primera versión para producir retrospectivamente una ejecución “perfecta”. La comparación entre intención y resultado es parte de la evidencia.

## Variante A → A’ → B → A

Si Lección 2 fue sólida, puedes sustituir la segunda repetición por una relación A’. Hazlo sólo como **discusión perceptiva de identidad**. No conviertas todavía la modificación en un catálogo de transformaciones: eso pertenece a Unidad 6.

## MÍNIMO PARA AVANZAR

- estableces A y puedes repetirlo;
- produces un B deliberadamente contrastante;
- recuperas A después de B;
- mantienes una referencia temporal suficiente;
- puedes escribir o representar la frase;
- puedes explicar qué hace que el último A sea un retorno reconocible.

## AMPLIACIÓN

Cambia únicamente B y conserva A exactamente. Compara cómo una sola decisión de contraste modifica el arco general sin alterar la identidad principal.
