## Objetivo

Completar ciclos cortos entre lectura, ejecución y escucha, localizando qué representación aporta información y cuál limita el intento.

La lección usa vocabulario conocido. **No intentes hacerla más difícil añadiendo notas nuevas.**

## 1. Recuperación fría · 3–4 min

Toca una microlectura sencilla de Fase 2 o una célula equivalente sin calentamiento específico prolongado.

Pregunta únicamente:

`¿ESTÁ DISPONIBLE LA LECTURA O NECESITO UN CORRECTIVO?`

No vuelvas a estudiar toda Fase 2.

## 2. Notación → ejecución → comparación · 8–10 min

Este material es **EJERCICIO ORIGINAL CREADO PARA ESTE CURSO**.

Antes de habilitar el audio:

1. localiza pulso y subdivisión;
2. toca directamente desde la partitura;
3. no memorices primero la secuencia;
4. decide cuál fue la dificultad principal;
5. habilita el audio y compara.

Clasifica el problema dominante como `LECTURA / PULSO-SUBDIVISIÓN / MOVIMIENTO / ATENCIÓN-MEMORIA / COMPRENSIÓN`.

## 3. Sonido → imitación · 6–7 min

Ahora la entrada es auditiva. La solución visual existe, pero permanece oculta mientras escuchas.

Compara posiciones de ataque y silencio; el contador de escuchas describe la condición del intento, no una nota." data-answer-score-src="/bateria/notation/f3/u1/f3-u1-l1-solucion-auditiva-a.musicxml" data-answer-score-title="30.U1.L1 — solución auditiva A"></div>

Proceso:

`ESCUCHAR → localizar pulso si ayuda → IMITAR con voz/manos/pad → REVELAR → COMPARAR`

No escribas todavía una reconstrucción completa. Ese paso será el centro de L2.

## 4. Nombra lo que acabas de hacer · 3–4 min

- escoger cuál de dos patrones sonaba igual sería **reconocimiento**;
- reproducir el estímulo fue **imitación**;
- escribirlo a partir del audio sería **dictado**;
- trabajar iterativamente sobre una grabación real será **transcripción**;
- explicar qué relación observas sería **análisis**.

La terminología sirve para no evaluar una cosa fingiendo que medimos otra.

## 5. Registro · 2 min

Anota:

- ayuda usada;
- número de escuchas del estímulo auditivo;
- variable limitante;
- un correctivo para la próxima sesión.

## MÍNIMO PARA AVANZAR

Puedes ejecutar una célula visual accesible, imitar una auditiva y explicar por qué esas dos tareas no aportan exactamente la misma evidencia.
