## Propósito

Esta evaluación cierra **esta unidad** y aporta la evidencia principal de **Hito 8 — Integración progresiva**.

No exige demostrar los recursos rítmicos trabajados en las unidades anteriores al nivel avanzado ni encadenarlos todos en una sola toma.

El criterio rector es:

`explicar → sentir referencia → ejecutar → aplicar → recuperar → revisar`

## Evidencias

### 1. Explicación

Presenta una pieza, estudio o improvisación breve y explica:

- forma;
- recurso o recursos avanzados usados;
- categoría correcta de cada fenómeno;
- referencia temporal;
- función musical;
- punto de resolución.

### 2. Pulso y referencia

Ejecuta el material conservando la referencia pertinente:

- pulso;
- subdivisión;
- métrica;
- ciclo común;
- duración puente;
- o referencia formal declarada.

### 3. Ejecución

Realiza una toma completa sin reiniciar por cada error local.

Se observa:

- continuidad;
- exactitud temporal suficiente;
- sonido/dinámica pertinentes;
- relajación razonable;
- claridad de transiciones;
- conservación de forma.

### 4. Aplicación

El recurso debe cumplir una función reconocible:

- tensión;
- contraste;
- desarrollo;
- transición;
- ambigüedad controlada;
- resolución;
- cambio de perspectiva temporal.

No basta con incluirlo.

### 5. Recuperación

Durante una segunda toma:

- acepta un error real, o simula la pérdida de un recurso;
- conserva la referencia principal;
- vuelve a una capa o motivo estable;
- reentra en un punto formal válido.

### 6. Lectura/escritura

Muestra al menos una de estas evidencias:

- leer una miniatura integrada del curso;
- escribir una estructura propia breve;
- anotar forma y recursos con suficiente precisión para reproducirlos.

### 7. Oído y revisión

Escucha una grabación y formula:

- una fortaleza observable;
- una variable limitante;
- una hipótesis sobre la causa;
- una corrección concreta;
- una decisión artística: mantener, simplificar, sustituir o desarrollar el recurso.

## MÍNIMO PARA AVANZAR — integración progresiva y experimental

Se alcanza cuando el alumno:

- combina **al menos un recurso avanzado** con pulso y forma claros;
- puede nombrar correctamente ese recurso;
- mantiene una referencia suficiente para completar la frase;
- aplica el recurso dentro de una estructura, no sólo como patrón aislado;
- puede salir o resolver sin detenerse siempre;
- distingue la complejidad de la función musical.

No se exige que todos los recursos rítmicos trabajados en las unidades anteriores estén funcionales simultáneamente.

## COMPETENTE / FUNCIONAL — integración progresiva y experimental

Se alcanza cuando el alumno, en tareas adecuadas:

- integra **varios recursos** manteniendo su identidad conceptual;
- conserva forma y referencia durante transiciones;
- explica qué hace cada recurso y por qué está allí;
- puede cambiar, eliminar o sustituir un recurso sin destruir la pieza;
- se recupera de un error preservando continuidad;
- compara versión compleja y reducida;
- usa grabación/escucha para revisar una decisión;
- crea o improvisa material donde la complejidad sirve a una intención reconocible.

## AVANZADO — integración progresiva y experimental

Indicadores opcionales:

- estructuras originales complejas pero comprensibles;
- polimetría y polirritmia integradas con control formal;
- modulaciones múltiples;
- ciclos largos y puntos de reencuentro usados como estructura;
- cambios deliberados de referencia perceptiva;
- improvisación extensa con narrativa, recuperación y control;
- mezcla de estilos o sistemas propios sin perder coherencia musical.

No es requisito para cerrar Fase 7.

## Hito 8 — criterio de cierre de Fase 7

La evidencia se considera suficiente cuando aparecen las cuatro dimensiones aprobadas:

### EXPLICACIÓN

El alumno sabe qué fenómeno ocurre y usa terminología suficientemente estricta.

### PULSO / REFERENCIA

Existe una referencia temporal mantenida o transformada conscientemente.

### EJECUCIÓN

El material puede tocarse con continuidad y recuperación razonables.

### APLICACIÓN

El recurso aparece dentro de una pieza, forma o improvisación y cumple una función musical explicable.

## Revisión de los recursos rítmicos trabajados en las unidades anteriores

No es un examen acumulativo de ocho técnicas. Usa esta tabla como **mapa de mantenimiento**:

| Capacidad | Nivel observado | Siguiente acción |
|---|---|---|
| Agrupaciones | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Desplazamientos | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Métricas impares y mixtas | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Tuplets | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Ciclos que cruzan compases | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Polirritmia | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Polimetría | mínimo / funcional / avanzado | continuar / mantener / reforzar |
| Modulación métrica | mínimo / funcional / avanzado | continuar / mantener / reforzar |

El nivel observado y la siguiente acción son dimensiones distintas: reforzar no es un nivel de competencia.

## Fallos que NO invalidan automáticamente el cierre

- un golpe aislado fuera de lugar si la forma continúa;
- necesitar un tempo moderado;
- no usar polimetría o modulación métrica en la pieza elegida;
- decidir simplificar después de escuchar;
- necesitar repetir una evidencia concreta otro día.

## Señales para repetir o reforzar

Conviene volver a una unidad concreta si:

- se confunden categorías de forma recurrente;
- la referencia temporal desaparece siempre al introducir complejidad;
- una relación sólo funciona memorizando una secuencia sin comprenderla;
- no puede recuperarse sin parar;
- la pieza existe sólo como sucesión de “trucos” sin forma reconocible.

## Cierre

Hito 8 puede resumirse así:

> **PUEDO ENTENDER UNA MANIPULACIÓN RÍTMICA AVANZADA, CONSERVAR O TRANSFORMAR SU REFERENCIA CONSCIENTEMENTE, EJECUTARLA Y USARLA POR UNA RAZÓN MUSICAL.**

Con esta evidencia, Fase 7 queda curricularmente cerrada sin afirmar que el estudio de ritmo avanzado haya terminado.
