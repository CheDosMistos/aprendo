## Qué demuestra este checkpoint

El objetivo es comprobar si el bombo está **disponible como primera voz de pie** a nivel H2 MÍNIMO.

No mide velocidad máxima ni premia una posición concreta de talón.

## Bloque A — Golpe y retorno

Produce una serie breve de golpes simples con pausa suficiente para observar:

`SONIDO / RETORNO / EQUILIBRIO / TENSIÓN`

Debes poder repetir el golpe sin que el cuerpo tenga que “reiniciarse” por completo cada vez.

## Bloque B — Patrón básico de bombo

El BPM se registra como condición; **no existe BPM de aprobado**.

## Bloque C — Sustitución manual → bombo

<div data-notation-score data-score-src="/bateria/notation/f4/u3/f4-u3-l4-kick-substitution.musicxml" data-score-title="40.U3.CP — Misma rejilla, nueva extremidad" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

Toca A → B → A y comprueba que la rejilla temporal sigue reconocible cuando el bombo sustituye ataques manuales.

## MÍNIMO PARA AVANZAR

Debe poder demostrarse razonablemente que:

- el asiento/pedal siguen configurados de forma sostenible dentro de H1;
- produces golpes simples de bombo controlados;
- el retorno/preparación permite golpes sucesivos;
- mantienes un patrón elemental de negras;
- mantienes corcheas sencillas o un equivalente básico;
- conservas pulso razonable sin depender de velocidad alta;
- identificas el principal fallo como `TIEMPO / SONIDO / RETORNO / TENSIÓN / EQUILIBRIO`;
- realizas un correctivo modificando una variable;
- al menos una sustitución manual→bombo conserva la rejilla;
- puedes explicar qué mecánica usas ahora sin presentarla como única técnica correcta.

## LO QUE NO CERTIFICA

Este checkpoint **no demuestra automáticamente**:

- H3 — hi-hat de pie;
- H4 — coordinación básica de cuatro extremidades;
- H5 — groove;
- H7 — independencia;
- dobles rápidos;
- doble pedal;
- heel-toe o slide funcional;
- dominio de heel-up y heel-down;
- velocidad alta;
- repertorio estilístico.

## COMPETENTE EN EL ÁMBITO DE U3

No es requisito para pasar a U4/U5, pero puedes registrar evidencia adicional si:

- controlas dos dinámicas;
- mantienes los patrones durante frases más largas;
- comparas dos resultados sonoros o mecánicas sin perder equilibrio;
- sustituyes más de una nota conocida por bombo manteniendo forma;
- recuperas tras un golpe fallido sin reiniciar siempre desde cero.

## Decisión

- **AVANZA:** H2 MÍNIMO está suficientemente disponible; U4 puede desarrollarse en paralelo y U5 podrá usar bombo muy simple.
- **AVANZA CON CORRECTIVO:** el patrón es funcional pero una dimensión necesita mantenimiento explícito.
- **REPITE EL BLOQUE ESPECÍFICO:** el problema principal impide todavía golpes básicos consistentes; no hace falta repetir toda U3.

La perfección no es requisito para continuar.
