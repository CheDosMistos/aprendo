## Objetivo

Escuchar una diferencia, realizar **un ajuste pequeño y reversible** y decidir por resultado.

> **AFINACIÓN ≠ BUSCAR UNA NOTA UNIVERSAL.**

La salida mínima de U6 no exige afinar por frecuencias prescritas ni memorizar una receta.

## Qué fuente estamos usando

Evans/D’Addario recomienda, entre otras prácticas, partir de tensión inicial uniforme, trabajar con giros pequeños y comparar el tono cerca de los tensores durante el proceso.

Eso se clasifica aquí como:

**TRADICIÓN TÉCNICA / GUÍA DE FABRICANTE.**

Fuente: [Evans / D’Addario — Drum Set Survival Guide](https://www.daddario.com/en-gb/blogs/percussion/drum-set-survival-guide).

No adoptamos como norma universal ninguna nota concreta sugerida por el fabricante para determinados parches o tambores.

## Protocolo A/B

### 1. Baseline

Graba 20–30 s de una tarea sencilla y escucha:

- ataque;
- cuerpo;
- duración;
- armónicos;
- respuesta de bordonera si procede;
- relación con las otras piezas.

### 2. Describe antes de tocar la llave

Usa palabras funcionales, no “bueno/malo”:

- demasiado largo para esta tarea;
- poco definido;
- desigual alrededor del parche;
- demasiada bordonera;
- caja demasiado dominante;
- tom que no separa bien su ataque.

### 3. Cambia una variable

Ejemplos permitidos:

- un ajuste pequeño y uniforme de tensión;
- corregir un tensor claramente desigual mediante comparación local;
- añadir una amortiguación removible;
- retirar parte de una amortiguación;
- cambiar zona/intención de golpe si el problema era ejecución y no el instrumento.

Haz cambios pequeños. Si no sabes qué efecto buscas, **no sigas girando por inercia**.

### 4. Toma B

Repite el mismo fragmento, mismo dispositivo y misma posición.

### 5. Decide

`MEJORA PARA ESTA TAREA / EMPEORA / NO ESTÁ CLARO`.

Si empeora, volver atrás es una decisión competente.

## Si no puedes o no debes ajustar físicamente el instrumento

La competencia H8 MÍNIMO también puede demostrarse mediante:

- balance dinámico;
- consistencia de zona;
- amortiguación reversible;
- configuración de registro;
- una decisión razonada de **no tocar la afinación todavía**.

No se fuerza una intervención mecánica sólo para “cumplir la lección”.

## AMPLIACIÓN

Cuando el oído y el procedimiento estén estables, compara:

- dos cantidades de amortiguación;
- relación entre parche batidor y resonante;
- sonido solo vs. sonido dentro de un groove.

No conviertas esta ampliación en una búsqueda infinita de precisión de tono.

## MÍNIMO PARA AVANZAR

- describes una diferencia sonora antes de intervenir;
- haces un cambio pequeño y reversible;
- comparas A/B en condiciones razonablemente constantes;
- puedes mantener o revertir el cambio con una razón;
- distingues guía de fabricante de norma científica;
- no necesitas una nota o frecuencia universal.
