## Objetivo

Entrar en Fase 5 sin convertir la primera sesión en un examen de todo lo aprendido.

La cadena ya es conocida:

`A → VARIACIÓN → A → FILL → A`.

## Primera pasada — modo diagnóstico

Tócala una vez en una condición cómoda.

Después clasifica sólo el problema dominante, si existe:

`PULSO / SUBDIVISIÓN / GROOVE / VARIACIÓN / FILL / 1 / BALANCE / TENSIÓN`.

Un fallo local hoy **no invalida un cierre anterior**.

## Correctivo

Usa:

`SÍNTOMA → HIPÓTESIS → PRUEBA → CORRECCIÓN → RECOMPONER`.

Ejemplos:

- si el fill desplaza el 1, aísla `fill → 1`;
- si la variación desestabiliza, vuelve temporalmente al Groove A;
- si el pie izquierdo añade tensión, reduce esa capa antes de cambiar otras variables.

No conviertas el correctivo en diez minutos de una célula de dos golpes. Vuelve pronto a la cadena.

## Elegir versión sostenible

Para Pieza A no necesitamos la versión más densa. Necesitamos una que pueda sostenerse durante más compases.

Puedes declarar conscientemente:

- `CORE 3 extremidades` si la cuarta capa roba demasiada atención;
- `CORE 4 extremidades` si ya es estable;
- `fill simplificado` si conserva duración y retorno;
- tempo reducido si mejora continuidad y relajación.

Simplificar deliberadamente **no es retroceder**: es controlar la dificultad para observar la nueva variable de esta unidad, que es la forma larga.

## Tempo

El archivo conserva 120 BPM como metadato técnico de Fase 4. No tienes que practicarlo a esa velocidad.

**No existe BPM de aprobado.**

## MÍNIMO PARA AVANZAR

- recuperas una versión reconocible de la cadena;
- identificas un único cuello de botella si aparece;
- aplicas un correctivo limitado;
- vuelves a la forma integrada;
- eliges una versión sostenible para trabajar Pieza A;
- mantienes ergonomía, carga y escucha segura.

## Registrar esta práctica

Anota `versión elegida → síntoma principal → correctivo → ¿mejoró al recomponer?`.
