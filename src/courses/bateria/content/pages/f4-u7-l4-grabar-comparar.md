## Objetivo

Usar una grabación breve para comprobar si la variación conserva la función del groove o introduce cambios accidentales.

No buscamos una toma «perfecta». Buscamos información útil.

## Toma 1 — referencia base

Toca cuatro compases de Groove A.

## Toma 2 — variación con retorno

<div data-notation-score data-score-src="/bateria/notation/f4/u7/f4-u7-l3-aaba-phrase.musicxml" data-score-title="Lección 4 — A–A–B–A" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

Toca la frase A–A–B–A.

## Escucha antes de corregir

Escucha una vez sin tocar y compara:

`PULSO / SUBDIVISIÓN / SONIDO / BALANCE / FORMA / INTENCIÓN / RETORNO / TENSIÓN VISIBLE`

Elige **1–2 prioridades**, no una lista infinita.

Preguntas útiles:

- ¿el golpe nuevo acelera o frena el compás 3?
- ¿ride/caja cambian de volumen al atender al bombo?
- ¿el tiempo 1 del compás 4 llega donde esperabas?
- ¿la variación suena como parte del groove o como una interrupción?

## Correctivo

`OBSERVACIÓN → HIPÓTESIS → CAMBIO DE UNA VARIABLE → NUEVA TOMA`

No subas BPM para esconder una transición incómoda.

## AMPLIACIÓN — segunda variación dinámica

Si A–A–B–A ya es estable, puedes elegir **un único acento dinámico fijo** de la mano de tiempo en un lugar formal claro y comparar otra toma.

No añadas notas. Esta ampliación no es requisito de la evaluación.

## MÍNIMO PARA AVANZAR

- realizas una toma base y una toma con variación;
- comparas estabilidad, balance y forma;
- localizas una diferencia observable;
- eliges como máximo 1–2 prioridades de corrección;
- repites después de un correctivo específico;
- no conviertes la grabación en una nota global de «bien/mal».

## Registrar esta práctica

Anota `toma → observación → prioridad → correctivo → nueva toma`.
