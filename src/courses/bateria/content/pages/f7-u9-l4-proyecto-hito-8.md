## Objetivo

Crear la evidencia principal de **Hito 8**:

`explicación + pulso + ejecución + aplicación`

No es un examen de velocidad ni una obligación de usar J1–J8 en la misma pieza.

## Formato del proyecto

Escoge una de dos vías:

### A — Composición breve

Entre 8 y 24 compases orientativos, ajustables a la idea.

### B — Improvisación con forma restringida

Entre 30 y 90 segundos orientativos, con secciones o puntos de referencia previamente definidos.

La duración no es criterio de aprobado. Debe ser suficiente para oír forma, desarrollo y resolución.

## Condiciones mínimas

Tu proyecto debe contener:

- una forma identificable;
- una referencia temporal que puedas describir;
- al menos **un recurso avanzado** utilizado intencionalmente;
- una salida o transformación formal clara;
- una explicación verbal breve;
- una grabación o intento completo sin detenerte por errores menores.

Esto satisface el nivel mínimo de J9 si pulso y forma permanecen claros.

## Condiciones para nivel funcional

Para mostrar J9 funcional, añade:

- varios recursos avanzados compatibles con la tarea;
- al menos una transición entre ellos;
- una decisión de tensión/resolución, contraste o transformación;
- recuperación ante un error o una simulación de error;
- una versión reducida para comparar el efecto musical.

No existe un número universal de recursos requerido. “Varios” significa que la integración sea observable, no que tengas que marcar casillas.

## PASO 1 — Mapa de forma

Antes de escribir notas, escribe algo como:

`A4 → B4 → C4 → A4`

Después asigna una función:

- A = referencia;
- B = transformación;
- C = máxima tensión;
- A = regreso.

Otra forma también es válida si puedes explicarla.

## PASO 2 — Selección de recursos

Haz una tabla sencilla:

| Sección | Función | Recurso | Referencia que debe sobrevivir |
|---|---|---|---|
| A | establecer | simple / J1 | negra + frase |
| B | desplazar | J2 o J5 | compás |
| C | tensión | J6/J7/J8 | ciclo común / duración puente |
| A | resolver | simplificación | forma |

Esta tabla es un **EJERCICIO ORIGINAL CREADO PARA ESTE CURSO**. No es una plantilla normativa externa.

## PASO 3 — Explicación previa

Graba 30–60 segundos de explicación o dila en voz alta:

1. cuál es la forma;
2. qué recurso avanzado aparece;
3. por qué pertenece a esa categoría;
4. qué referencia mantienes;
5. dónde y cómo resuelve.

Si la explicación necesita frases vagas como “aquí hago algo raro”, vuelve a F2 y a la unidad correspondiente.

## PASO 4 — Primera interpretación completa

Regla:

> **no te detengas por un error local si puedes conservar tiempo y forma.**

Al terminar, registra:

- dónde se perdió pulso;
- dónde se perdió forma;
- qué transición falló;
- si la recuperación fue musical;
- si la intención se oyó.

## PASO 5 — Prueba de reducción

Crea una segunda versión donde elimines el recurso más complejo.

Conserva:

- forma;
- dinámica general;
- motivo;
- duración de secciones.

Compara:

- ¿la versión compleja añade una función real?;
- ¿la versión simple comunica mejor?;
- ¿hay una tercera solución más eficaz?

Eliminar complejidad después de probarla también puede ser una decisión musical avanzada.

## PASO 6 — Revisión

Usa la cadena de práctica del curso:

`síntoma → hipótesis → prueba → corrección → correctivo → transferencia`

Ejemplos:

- **síntoma:** el regreso a A llega tarde;
- **hipótesis:** pierdo la frase durante el ciclo trans-barra;
- **prueba:** tocar sólo forma + acentos de sección;
- **corrección:** mantener una referencia vocal de compases;
- **correctivo:** practicar dos compases antes y dos después de la transición;
- **transferencia:** volver a la pieza completa.

## Oído

Escucha sin partitura y escribe de memoria:

- forma;
- puntos de tensión;
- dónde cambia la referencia;
- dónde resuelve.

Después compara con tu plan original.

Si el mapa escuchado difiere mucho del mapa escrito, decide si:

- la ejecución falló;
- la composición no comunica la forma prevista;
- o descubriste una interpretación mejor y quieres reescribir el plan.

## Lectura y escritura

Si la pieza está escrita, revisa que:

- cada compás cierre;
- los tuplets declaren su relación;
- las métricas sean reales y no etiquetas decorativas;
- los desplazamientos no se confundan con cambios de compás;
- la polirritmia/polimetría, si aparecen, estén representadas de forma comprensible;
- cualquier partitura creada por ti se identifique como material original.

## Kit

Si ya hay batería:

- orquesta por función, no por “usar todas las piezas”;
- conserva una versión de pad/caja para comprobar si la idea depende del timbre;
- añade pies después de que la estructura temporal sea estable;
- usa dinámica y sonido como parte de la forma.

Si aún no hay kit, el proyecto puede cerrarse plenamente en pad, voz, palmas, lectura y grabación.

## Criterio de avance

Tu proyecto demuestra el objetivo cuando puedes:

- explicar la estructura;
- mantener la referencia;
- tocar o improvisar la forma completa;
- aplicar el recurso con intención;
- recuperarte sin abandonar toda la pieza;
- comparar versión compleja y reducida;
- justificar al menos una revisión basada en la escucha.

Eso es Hito 8 mucho más que una cifra de BPM.
