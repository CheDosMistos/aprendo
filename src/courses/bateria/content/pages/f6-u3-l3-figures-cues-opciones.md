## Objetivo

Leer la información del chart según su **función musical**, no según la cantidad de tinta.

Una figure escrita, un cue y una indicación de textura pueden exigir respuestas diferentes.

## 1. Pregunta qué te está pidiendo el símbolo

Antes de tocar una marca, distingue:

- **COINCIDENCIA:** un evento rítmico necesita alinearse con el arreglo;
- **ANTICIPACIÓN:** un cue te avisa de algo que viene;
- **TEXTURA:** una indicación orienta densidad, superficie o carácter;
- **DINÁMICA:** pide una relación de intensidad;
- **NAVEGACIÓN:** te sitúa en la forma;
- **ESPACIO DE DECISIÓN:** el chart no prescribe cada golpe.

No todas las marcas tienen una única interpretación fuera de contexto.

## 2. Figures: primero ritmo y punto de llegada

Cuando una figure sea relevante:

1. identifica su colocación respecto al pulso;
2. canta o toca el ritmo sin orquestación compleja;
3. localiza su punto de resolución;
4. decide una respuesta que permita volver al tiempo.

La orquestación puede variar si el chart no la especifica y el contexto lo permite.

## 3. Cue no significa «toca esto»

Un cue puede representar información de otra voz para ayudarte a anticipar una entrada, un corte o una transición.

La pregunta correcta es:

> **¿QUÉ DECISIÓN ME PERMITE TOMAR ESTA INFORMACIÓN?**

No conviertas automáticamente cada cue en un golpe de batería.

## 4. Construye tres niveles de respuesta

Para un evento difícil prepara:

- **RESPUESTA COMPLETA:** versión que buscas ejecutar cuando la atención lo permite;
- **RESPUESTA FUNCIONAL:** conserva ritmo/punto estructural con menor complejidad;
- **RESPUESTA DE SEGURIDAD:** mantiene tiempo y forma aunque omita el detalle.

Las tres deben compartir la función esencial.

## 5. Evita sobreinterpretar charts originales o externos

Un chart condensado no demuestra qué tocó un baterista concreto en una grabación.

Si el curso crea una respuesta a una figure, se trata como **EJERCICIO ORIGINAL CREADO PARA ESTE CURSO** o decisión interpretativa, no como transcripción auténtica.

## Ejercicio original creado para este curso

Selecciona tres eventos de un chart original Aprendo:

1. una figure;
2. un cue;
3. una indicación de textura/dinámica.

Para cada uno escribe:

`FUNCIÓN → RESPUESTA COMPLETA → RESPUESTA FUNCIONAL → QUÉ NO DEBE PERDERSE`

Después toca una pasada eligiendo en tiempo real la versión que puedas sostener sin sacrificar forma.

## Errores frecuentes

- tocar todos los cues como hits;
- ornamentar una figure antes de entender su ritmo;
- resolver una figure y no volver al groove;
- asumir una orquestación no escrita como obligatoria;
- confundir un chart funcional con una transcripción exacta.

## MÍNIMO PARA AVANZAR

- distingues figure, cue, navegación y espacio de decisión;
- puedes reducir una figure a su ritmo esencial;
- preparas una respuesta funcional y una de seguridad;
- vuelves al tiempo después del evento;
- no atribuyes tu respuesta original a una interpretación externa sin fuente.

**No existe BPM de aprobado.**
