## Qué se intenta demostrar

El criterio superior de transferencia entre estilos en **MÍNIMO PARA AVANZAR** es:

> **Identifica un principio compartido entre estilos.**

Esta unidad lo operacionaliza sin crear una rúbrica paralela:

> compara dos contextos, identifica una función o principio compartido, distingue al menos una diferencia de realización y demuestra una transferencia controlada explicando qué conserva y qué transforma.

## Tarea A — Comparación documentada

Selecciona dos referencias legales y documentadas de estilos distintos ya trabajados.

Registra:

1. una función compartida;
2. una diferencia de realización;
3. un rasgo que no trasladarías automáticamente;
4. una afirmación que **no** puedes generalizar desde esas dos grabaciones.

La respuesta debe basarse en lo que escuchas o en fuentes verificadas, no en clichés estilísticos.

## Tarea B — Transferencia A → B

**EJERCICIO ORIGINAL CREADO PARA ESTE CURSO.**

Usa una idea rítmica propia y sencilla.

1. Define su función en A.
2. Toca/graba A.
3. Cambia una sola variable relevante para B.
4. Toca/graba B.
5. Explica `QUÉ CONSERVÉ → QUÉ CAMBIÉ → QUÉ EFECTO ESCUCHÉ`.

No se exige que B sea estilísticamente «perfecto». Sí que la decisión sea consciente, justificable y musicalmente funcional.

## Tarea C — Transferencia nueva

Repite el procedimiento con otro par de referencias o una segunda variable no ensayada exactamente igual.

Esta tarea comprueba que el resultado no depende sólo de memorizar la primera transformación.

## Tarea D — Híbrido opcional

Crea 8–16 compases propios combinando un elemento de A y otro de B con una función central declarada.

Esta tarea explora el perfil avanzado de transferencia entre estilos, pero **no es requisito para demostrar MÍNIMO**.

## Dimensiones críticas observables

Compatible con `06_SISTEMA_PRACTICA_Y_EVALUACION`:

- **comprensión:** distingue función y realización;
- **transferencia:** aplica un principio bajo una condición estilística diferente;
- **tiempo/subdivisión:** mantiene continuidad suficiente durante la transformación;
- **exactitud/forma:** conserva la estructura prevista de la tarea;
- **dinámica/sonido/articulación:** cuando son la variable elegida, el cambio es intencional;
- **retención/recuperación:** cuando proceda, la idea sigue disponible en una sesión posterior o tras una toma fallida.

No se promedian estas dimensiones como nota numérica.

## MÍNIMO PARA AVANZAR — transferencia entre estilos

Existe evidencia suficiente cuando:

- identificas al menos un principio compartido entre dos estilos/contextos;
- distingues ese principio de su realización concreta;
- evitas presentar un único ejemplo como regla universal del género;
- haces al menos una transferencia controlada de material propio;
- puedes explicar qué conservaste y qué transformaste;
- mantienes continuidad suficiente para que la comparación tenga sentido musical.

## COMPETENTE / FUNCIONAL — evidencia orientativa

El mapa superior fija:

> **Reutiliza vocabulario conscientemente sin borrar el carácter estilístico.**

Busca progresivamente:

- transferencias consistentes entre más de un par de contextos;
- decisiones justificables de densidad, articulación, orquestación, espacio o función;
- menor dependencia de una receta fija;
- capacidad de rechazar una transferencia cuando perjudica el carácter;
- uso de referencias y repertorio para revisar decisiones.

## AVANZADO — evidencia orientativa

El mapa superior fija:

> **Combina lenguajes y crea híbridos con intención musical.**

Esto requiere más amplitud, conocimiento contextual y capacidad de combinación deliberada. Esta unidad puede abrir esa puerta, pero **no exige este nivel para continuar**.

## Decisión

Usa el lenguaje aprobado:

- **CONTINUAR** — transferencia entre estilos MÍNIMO está suficientemente demostrado;
- **CONTINUAR + CORRECTIVO** — existe una fragilidad localizada, pero el principio compartido y la transferencia básica son observables;
- **REDUCIR NOVEDAD** — el alumno todavía copia superficies sin poder explicar función/diferencia o pierde sistemáticamente la continuidad;
- **DETENER CARGA** — sólo cuando corresponda por salud/carga según el sistema general.

## Fronteras de certificación

Esta evaluación:

- no certifica dominio completo de ningún estilo;
- no convierte una grabación en definición de una tradición;
- no evalúa recetas de microtiming: corresponde a Unidad 8;
- no sustituye el proyecto sostenido de Unidad 10;
- **no declara Hito 7**;
- no abre el núcleo avanzado de Fase 7;
- no usa BPM universal de aprobado.

> **Evaluación = PRINCIPIO COMPARTIDO IDENTIFICADO + TRANSFERENCIA CONTROLADA Y EXPLICADA.**
