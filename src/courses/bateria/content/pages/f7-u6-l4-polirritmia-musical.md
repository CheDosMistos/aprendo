## Objetivo

Usar una polirritmia como **recurso musical intencional** conservando tres cosas a la vez:

1. identidad de cada capa;
2. ciclo común;
3. forma musical reconocible.

## Principio

> **La complejidad sólo aporta si puedes seguir oyendo qué función cumple cada capa y dónde resuelve la relación.**

No hace falta aumentar la dificultad para que polirritmia sea musical.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — K: una capa estructural y otra expresiva

Usa `3:2`.

- capa 2: dinámica estable y función de referencia;
- capa 3: dinámica variable y acentos deliberados.

Haz después lo contrario:

- capa 3 = referencia estable;
- capa 2 = capa expresiva.

### Condición

Los cambios de dinámica no pueden alterar los intervalos de ninguna capa.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — L: timbre sin deformación

En pad puedes simular contraste mediante:

- centro/borde;
- dinámica;
- alturas de baqueta.

En kit:

- una capa en plato/hi-hat;
- otra en caja/tom/bombo.

Primero conserva un timbre fijo por capa. Después permite una orquestación sencilla dentro de una de ellas.

La capa debe seguir siendo reconocible aunque cambie de superficie.

## Composición breve

### EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — M: forma de 8 compases

Diseña:

- compases 1–2: referencia simple;
- compases 3–4: `3:2`;
- compases 5–6: regreso a referencia simple o variación;
- compases 7–8: `3:2` o `4:3` con resolución clara.

Condiciones:

- no cambies de compás sólo para facilitar la relación;
- no redefinas el tempo;
- el comienzo de cada sección debe ser reconocible;
- debe existir un elemento motívico común entre la parte simple y la polirrítmica.

## Improvisación restringida

Durante 8 barras:

- mantén una capa periódica estable;
- improvisa sólo dinámica, timbre o silencios en la otra;
- cada 2 barras comprueba conscientemente el punto de ciclo común;
- si pierdes la relación, simplifica la capa expresiva antes de detener la referencia.

La restricción busca preservar la estructura mientras aparece libertad.

## Silencios dentro de una capa

Puedes retirar un ataque de una capa como recurso musical, pero debes seguir sintiendo su posición temporal.

Ejemplo conceptual en capa 3:

```text
ciclo 1: X X X
ciclo 2: X - X
ciclo 3: X X X
```

El silencio no autoriza a reespaciar los otros dos ataques.

## Qué ocurre si una capa deja de ser periódica

Si modificas tanto una capa que ya no conserva periodicidad, quizá sigas teniendo una frase rítmica interesante, pero la etiqueta `3:2` o `4:3` puede dejar de describir con precisión lo que suena.

En esta unidad preferimos **menos transformación y más claridad analítica**.

## Frontera con polimetría

No declares polimetría sólo porque las capas “parezcan estar en compases distintos”.

En los ejercicios centrales de esta unidad:

- existe un ciclo compartido explícito;
- la barra de referencia permanece clara;
- no asignamos a cada capa una barra independiente que deba mantener su propio ciclo métrico a través de varias barras.

Ese cambio de nivel estructural será el objeto de Unidad 7.

## Frontera con modulación métrica

No uses la capa de 3 o 4 para redefinir el tempo de la sección siguiente en esta unidad.

Puedes escuchar la posibilidad, pero la reinterpretación calculada de una subdivisión como nuevo pulso pertenece a modulación métrica.

## Oído y análisis propio

Graba una forma de 8 barras y escucha sin tocar.

Pregunta:

1. ¿puedo seguir la capa 2/4?;
2. ¿puedo seguir la capa 3?;
3. ¿puedo anticipar los puntos comunes?;
4. ¿la polirritmia aparece como tensión, textura o dirección formal?;
5. ¿la forma sigue siendo comprensible?

## Recuperación musical

Practica dos fallos deliberados:

### Fallo A — se pierde la capa expresiva

Mantén la referencia, espera al siguiente comienzo de ciclo y reentra.

### Fallo B — se pierde la capa de referencia

Conserva la otra periodicidad, localiza el ciclo común y reconstruye la referencia desde allí.

No intentes “compensar” añadiendo ataques intermedios.

## Aplicación al kit

Tres niveles:

1. **dos superficies / dos manos**;
2. **mano + pie** si la coordinación lo permite;
3. **capa de groove + capa polirrítmica** como AMPLIACIÓN, sólo si el groove no desaparece bajo la tarea.

No conviertas independencia extrema en requisito de polirritmia funcional.

## Criterio de avance

Puedes usar `3:2` o `4:3` en una frase o forma breve, cambiar dinámica/timbre de una capa sin deformar el ratio, conservar el ciclo común y explicar por qué el resultado sigue siendo polirritmia y todavía no polimetría/modulación métrica.
