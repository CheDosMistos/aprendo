## Objetivo

Mantener una capa funcional estable mientras una segunda voz cambia sin arrastrar el pulso ni deformar involuntariamente la base.

## 1. Define funciones, no sólo extremidades

Describe primero qué hace cada capa:

- mantener referencia temporal;
- articular backbeat;
- sostener ostinato de pie;
- responder con una voz secundaria;
- crear textura;
- marcar frase.

«Mano derecha + pie izquierdo» describe extremidades; no explica todavía la función musical.

## 2. Fija una capa y limita el vocabulario variable

Mantén la base durante varios ciclos y permite a la voz secundaria sólo unas pocas posiciones conocidas.

**EJERCICIO ORIGINAL CREADO PARA ESTE CURSO:** empieza con una variación por ciclo. Cuando la base sobreviva con relajación y buen sonido, usa dos variaciones y después cambia el orden.

## 3. Conserva la jerarquía

Si la voz variable amenaza la estabilidad:

`PULSO → CAPA BASE → FUNCIÓN DE LA VARIACIÓN → DENSIDAD`

Reduce la última variable necesaria, no aceleres ni aprietes para «salvar» la combinación.

## 4. Alterna foco atencional

En pasadas distintas escucha deliberadamente:

- sólo la base;
- sólo la voz variable;
- balance entre ambas;
- resultado musical global.

El objetivo no es mantener conscientemente cada detalle para siempre, sino comprobar que ninguna capa funciona sólo porque has dejado de escucharla.

## 5. Introduce variabilidad sin perder representación

Cuando una combinación está disponible:

- cambia el orden de dos eventos;
- elimina una nota;
- desplaza una única respuesta a otra posición conocida;
- cambia la orquestación sin cambiar el ritmo;
- alterna dos ciclos distintos.

Cambia una dimensión dominante cada vez durante adquisición y recombínalas después.

## Errores frecuentes

- añadir demasiadas posiciones de golpe;
- tocar la voz secundaria más fuerte porque exige más atención;
- dejar que el ostinato se convierta en una secuencia aproximada;
- confundir una repetición memorizada con independencia transferible;
- continuar cuando la tensión aumenta ciclo a ciclo.

## MÍNIMO PARA AVANZAR

- mantienes una capa base estable durante varios ciclos;
- una voz secundaria puede variar dentro de un vocabulario limitado;
- el pulso no se acelera ni desacelera para acomodar la variación;
- puedes escuchar cada capa por separado dentro de la combinación;
- reduces densidad cuando la función empieza a degradarse;
- el ejercicio termina en una aplicación musical reconocible.
