## Objetivo

Nombrar **qué** se rompe dentro del Patrón A y comprobar si el correctivo mejora realmente el conjunto.

No se crea material rítmico nuevo.

## Vocabulario de diagnóstico

`ANTICIPA / ARRASTRA / DESAPARECE / DUPLICA / CAMBIA DINÁMICA / ROMPE SUBDIVISIÓN / ALTERA BALANCE`

Ejemplos observables:

- el pie izquierdo llega antes de la caja en 2;
- el bombo de 3 arrastra las corcheas siguientes;
- la mano de ride pierde el “&” después de una coincidencia;
- la caja aumenta mucho de volumen al entrar el pie izquierdo;
- el cuerpo se inclina o bloquea para accionar un pedal.

## Secuencia correctiva

`PATRÓN COMPLETO → localizar unión → aislar sólo si hace falta → practicar unión → RECOMPONER`

Puntos útiles:

- **2 y 4:** ride + caja + chick de pie izquierdo;
- **1 y 3:** ride + bombo;
- **&:** sólo la mano de tiempo sigue sonando.

No practiques todas las combinaciones posibles “por si acaso”. Aísla sólo lo que el diagnóstico señale.

## Hipótesis ≠ hecho

Puedes formular una hipótesis —por ejemplo, “mi pie izquierdo anticipa porque tenso demasiado la pierna”—, pero registra por separado:

- **síntoma observado**;
- **hipótesis de causa**;
- **correctivo probado**;
- **resultado al recomponer**.

## MÍNIMO PARA AVANZAR

- identificas una extremidad/transición concreta;
- aplicas un correctivo de una variable;
- recompone las cuatro extremidades;
- verificas si hubo transferencia;
- no conviertes el aislamiento en rutina permanente.

## Registrar esta práctica

Anota `síntoma → hipótesis → correctivo → patrón completo → resultado`.
