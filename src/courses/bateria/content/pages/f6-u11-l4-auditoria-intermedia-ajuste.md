## Objetivo

Demostrar la parte más importante de autonomía en esta unidad: **modificar el plan por evidencia**, no por aburrimiento, superstición ni obediencia a la primera idea.

Cadena de esta lección:

`PREDICCIÓN → RESULTADO → DISCREPANCIA → INTERPRETACIÓN → AJUSTE → RETEST`

## No todo resultado negativo significa lo mismo

Si la estrategia no produce el cambio esperado, pueden estar ocurriendo cosas diferentes:

- la hipótesis era incorrecta;
- la estrategia no atacaba realmente la hipótesis;
- el recurso añadía una ayuda que ocultaba el problema;
- la prueba era demasiado difícil o demasiado fácil;
- la evidencia elegida no era sensible al cambio buscado;
- el proyecto tiene demasiadas novedades simultáneas;
- el tiempo disponible fue insuficiente para afirmar nada con seguridad.

La respuesta competente no es «funcionó / no funcionó». Es preguntar **qué parte del razonamiento debe actualizarse**.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — «Auditoría hipótesis → prueba → resultado»

Completa una fila por decisión importante:

| Elemento | Registro |
|---|---|
| Hipótesis inicial | qué creías que limitaba el resultado |
| Predicción | qué esperabas observar si era razonable |
| Intervención | qué cambiaste |
| Resultado | qué ocurrió realmente |
| Confianza actual | aumenta / disminuye / no cambia |
| Decisión | mantener / cambiar / reducir / retirar / volver a medir |
| Razón | qué evidencia justifica la decisión |

No uses porcentajes de «confianza» inventados. La escala es cualitativa porque la información disponible no permite una probabilidad calibrada.

## Cuatro ajustes diferentes

### 1. MANTENER

La estrategia sigue siendo plausible y la evidencia es compatible con la predicción. No significa que ya esté demostrada para siempre.

### 2. CAMBIAR

La evidencia contradice la hipótesis o la intervención no aporta información suficiente. Cambia una variable relevante, no todo a la vez.

### 3. REDUCIR

El proyecto contiene demasiada carga. Simplifica alcance, densidad, ayuda o dificultad sin abandonar la función musical central.

### 4. RETIRAR

Una ayuda cumplió su función y ahora necesitas comprobar si el aprendizaje sobrevive sin ella.

## Error de coste hundido

Haber invertido varias sesiones en una estrategia no la convierte en correcta.

Esta unidad no premia «aguantar» una intervención ineficaz. Premia conservar trazabilidad:

> **LA CAMBIÉ PORQUE LA EVIDENCIA X CONTRADECÍA LA PREDICCIÓN Y.**

## Error opuesto: cambiar demasiado pronto

Tampoco conviertas cada toma imperfecta en una razón para saltar a otra estrategia.

Antes de cambiar, pregunta:

- ¿la prueba fue ejecutada en condiciones comparables?
- ¿la variable objetivo era observable?
- ¿el fallo es local o estructural?
- ¿hay suficiente evidencia para afirmar algo o sólo una toma aislada?

La unidad no fija un número universal de intentos.

## FUENTE MARCO — aprendizaje autodirigido

Parkes describe autogestión, automonitorización y modificación de la propia conducta como componentes de estrategias autodirigidas en contextos musicales. Esta unidad traduce esa idea a una regla curricular: **un plan autónomo debe poder modificarse**, no sólo diseñarse.

Fuente: https://doi.org/10.1093/oxfordhb/9780190056285.013.7

## Revisión de la dificultad

Una auditoría puede concluir que el material era inadecuado.

Eso no invalida todo el proyecto. Registra:

1. qué señal mostró el exceso de carga;
2. qué parte conservarás;
3. qué reducción mantiene la misma pregunta musical;
4. qué competencia debe consolidarse antes de volver al alcance original.

## Volver a música

Después de ajustar, realiza un retest en una condición musical representativa.

Si el correctivo sólo mejora el ejercicio auxiliar y no vuelve al repertorio, todavía no has demostrado que resuelva el problema original.

## Rutina mínima

- comparar una predicción con un resultado;
- tomar una decisión de mantener/cambiar/reducir/retirar;
- justificarla con una observación concreta;
- volver a música.

## Rutina estándar

- recuperar el estado del proyecto sin reconstruir todo el correctivo;
- revisar una evidencia intermedia;
- actualizar hipótesis o estrategia;
- ejecutar el ajuste;
- retest musical;
- registrar siguiente decisión.

## Criterio de avance

### MÍNIMO PARA AVANZAR

Puedes mostrar al menos una decisión revisada por evidencia y explicar qué dato motivó el cambio o la continuidad.

### COMPETENTE / FUNCIONAL

Distingues entre cambiar hipótesis, estrategia, recurso o alcance y eliges la modificación mínima que produzca información útil.

### AVANZADO

Opcionalmente identificas una inferencia que todavía no puedes hacer y diseñas una prueba posterior para reducir esa incertidumbre.

## Autoevaluación

- ¿estoy defendiendo el plan porque funciona o porque ya invertí tiempo?
- ¿cambié demasiadas variables a la vez?
- ¿mi retest vuelve al problema musical original?
- ¿puedo explicar qué aprendí incluso si la primera estrategia falló?
