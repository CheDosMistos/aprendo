## Objetivo

Mantener una base de pies ya conocida debajo de una orquestación manual también conocida.

La novedad dominante sigue siendo **orquestar sin perder identidad**. Los pies no reciben vocabulario nuevo.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — ORQUESTACIÓN + BASE DE PIES

<div data-notation-score data-score-src="/bateria/notation/f4/u8/f4-u8-l2-orchestration-feet.musicxml" data-score-title="Unidad 8.Lección 2 — Orquestación + base de pies" data-score-badge="EJERCICIO ORIGINAL CREADO PARA ESTE CURSO"></div>

Manos:

- ocho corcheas exactamente como Unidad 2.Lección 4;
- R/L preservado;
- caja + tom agudo + tom grave;
- acentos preservados.

Pies:

- bombo: 1 y 3;
- pedal hi-hat: 2 y 4.

## Construcción

1. Recupera la frase de manos.
2. Toca sólo la base de pies.
3. Combina manos + bombo.
4. Añade el chick 2/4.
5. Recompón el patrón completo.

Si los pies hacen que desaparezca una nota manual, no inventes otra digitación de inmediato. Localiza primero la coincidencia problemática.

## Diagnóstico

`MANOS / PIE DERECHO / PIE IZQUIERDO / TRANSICIÓN DE SUPERFICIE / PULSO / BALANCE / TENSIÓN`

Aislar una coincidencia es un **correctivo**, no la nueva forma del ejercicio.

## Tempo

El archivo usa 120 BPM como referencia técnica. Ajusta el tempo real hasta poder escuchar y observar todas las capas.

**No existe BPM de aprobado.**

## MÍNIMO PARA AVANZAR

- la frase manual sigue reconocible con pies;
- bombo 1/3 y chick 2/4 permanecen suficientemente estables;
- el recorrido caja/toms no cambia accidentalmente de densidad;
- identificas una coincidencia problemática si aparece;
- puedes aislarla y recomponer;
- mantienes ergonomía y escucha segura.

## Registrar esta práctica

Anota `frase + pies → coincidencia frágil → correctivo → conjunto`.
