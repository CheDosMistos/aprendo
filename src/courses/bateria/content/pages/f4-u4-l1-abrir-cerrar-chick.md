## Objetivo

Controlar **abierto / cerrado** y producir un chick de pie repetible sin perder equilibrio.

Hoy no hay manos, bombo ni ostinato continuo: primero necesitas conocer el recorrido útil del pedal.

## El hardware es una variable

La distancia entre platos, la tensión o resistencia del mecanismo y el recorrido del pedal dependen del instrumento y de su ajuste.

No fijamos una separación, presión ni recorrido universales. Para ajustes concretos del hardware, sigue el manual del instrumento y comprueba el resultado real.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — ABRE / CIERRA / ESCUCHA / PREPARA

1. Parte de un cierre cómodo.
2. Reduce presión hasta permitir una apertura controlada.
3. Vuelve a cerrar.
4. Escucha el contacto de los platos.
5. Deja el pie preparado para repetir.
6. Pausa y vuelve a empezar.

La pausa sirve para observar, no para “hacer trampa”.

## Qué observar

`SONIDO / CIERRE / RETORNO / EQUILIBRIO / TENSIÓN`

- **SONIDO:** ¿el chick aparece claramente sin necesidad de aplastar el pedal?
- **CIERRE:** ¿los platos llegan al estado que buscabas?
- **RETORNO:** ¿puedes liberar y volver a cerrar de forma predecible?
- **EQUILIBRIO:** ¿el torso y la pierna derecha permanecen estables?
- **TENSIÓN:** ¿aprietas pie/pantorrilla/cadera más de lo necesario?

## Corrige una sola variable

Si falla el cierre, prueba una hipótesis antes de repetir muchas veces:

`SÍNTOMA → HIPÓTESIS → CAMBIO → EFECTO`

Ejemplos:

- cierre débil → quizá falta recorrido útil → ajusta una variable y compara;
- equilibrio cambia → quizá el asiento/distancia no ayuda → vuelve a setup, ergonomía y ecología del kit;
- pie se queda rígido → reduce intensidad y comprueba si el cierre sigue siendo suficiente.

## MÍNIMO PARA AVANZAR

- abres y cierras de forma intencional;
- produces varios chicks reconocibles;
- el pie vuelve a una posición utilizable;
- conservas equilibrio razonable;
- puedes identificar un cuello de botella;
- aplicas un correctivo sin cambiar cinco cosas a la vez.

## Seguridad y carga

Dolor persistente, hormigueo, entumecimiento, pérdida de fuerza/control o movimientos involuntarios persistentes no se normalizan como aprendizaje. Reduce o detén la carga y busca valoración profesional si persisten.

## Registrar esta práctica

Anota `problema → cambio → efecto`. Completar la lección no demuestra por sí solo hi-hat de pie MÍNIMO.
