## Objetivo

Repetir golpes simples de bombo dentro de **negras y corcheas conocidas** sin convertir el tempo en criterio de aprobado.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — PULSO DE BOMBO

La partitura contiene dos compases originales de 4/4:

- compás A — cuatro negras de bombo;
- compás B — ocho corcheas de bombo.

No hay manos, dobles técnicos ni dificultad rítmica nueva.

## Proceso

1. Lee y cuenta el compás A antes de tocar.
2. Tócalo a un tempo cómodo.
3. Escucha si los ataques se adelantan o atrasan.
4. Repite el compás B conservando la misma subdivisión interna.
5. Si el sonido cambia mucho al avanzar, comprueba fatiga/tensión antes de subir tempo.
6. Si ambos patrones son estables, prueba una segunda dinámica moderada.

## Diagnóstico

`TIEMPO / SONIDO / RETORNO / TENSIÓN / EQUILIBRIO`

- **TIEMPO:** ¿el golpe entra antes/después del pulso?
- **SONIDO:** ¿la intensidad cambia sin intención?
- **RETORNO:** ¿el pedal queda preparado para el siguiente ataque?
- **TENSIÓN:** ¿aparece rigidez creciente al encadenar golpes?
- **EQUILIBRIO:** ¿el cuerpo empieza a compensar?

No corrijas las cinco variables a la vez. Elige una hipótesis.

## Metrónomo

El BPM es una **condición de práctica**, no una nota. Baja el tempo si necesitas recuperar control; vuelve a aumentarlo sólo si la representación del patrón sigue estable.

## MÍNIMO PARA AVANZAR

- mantienes negras de bombo con pulso razonable;
- mantienes corcheas sencillas o un equivalente elemental;
- el sonido no colapsa sistemáticamente al encadenar golpes;
- puedes detectar el cuello de botella principal;
- no necesitas velocidad alta para considerar bombo en progreso;
- conservas equilibrio y carga razonables.

## Registrar esta práctica

Guarda una toma breve si aporta valor y anota `condición → problema → correctivo → efecto`.
