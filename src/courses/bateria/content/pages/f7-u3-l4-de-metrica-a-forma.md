## Objetivo

Usar una métrica impar o mixta para **construir una frase reconocible**, no sólo para demostrar que puedes contar una barra rara.

La competencia J3 se vuelve musical cuando puedes decidir:

- por qué dura así una frase;
- dónde genera tensión;
- dónde ofrece una referencia clara;
- cómo vuelve a una zona estable;
- qué hacer si pierdes una barra sin abandonar la música.

## Principio: la firma no es la música

Un `7/8` puede sonar rígido, fluido, pesado, ligero o casi invisible. La firma describe la organización métrica escrita; el resultado musical depende además de:

- acentos;
- densidad;
- dinámica;
- orquestación;
- silencios;
- repetición y variación;
- relación con el resto de la forma.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — F: forma de ocho barras

Construye una forma con esta arquitectura:

1. barras 1–2: `4/4`, material estable;
2. barras 3–4: `5/4`, una misma idea organizada `3+2`;
3. barras 5–6: `7/8`, una misma idea organizada `2+2+3`;
4. barras 7–8: `4/4`, regreso y resolución.

### Restricciones

- conserva una corchea temporalmente estable durante toda la forma;
- no cruces deliberadamente una célula incompatible a través de barras: eso pertenece a J5;
- no introduzcas tuplets como variable principal: J4 será la unidad siguiente;
- no cambies el tempo para “hacer encajar” una barra;
- deja al menos un elemento reconocible entre secciones: sticking, timbre, contorno acentual o dinámica.

## Versión pad

Elige una célula muy simple de ataques y silencios que puedas recordar sin esfuerzo.

Primera pasada:

- conserva el sticking;
- cambia sólo la capacidad de las barras;
- marca el `1` con un acento moderado.

Segunda pasada:

- reduce el acento del `1`;
- mantén la forma por percepción interna;
- graba las ocho barras.

## Versión kit

Mantén un elemento ancla, por ejemplo:

- hi-hat/ride sobre la unidad de corchea;
- caja con una función de backbeat adaptada a cada barra;
- bombo revelando comienzos de grupo.

Después prueba lo contrario: haz que el plato exprese los grupos mientras bombo/caja mantienen una identidad de frase común.

## Composición: decidir antes de tocar

Escribe primero un mapa de ocho barras con:

- firma;
- agrupación;
- función: `estable / tensión / transición / resolución`;
- una indicación dinámica.

Sólo después crea los ataques concretos.

Este orden evita que una colección de patrones difíciles suplante a la forma.

## Improvisación restringida

Improvisa dentro de la misma forma de ocho barras, pero conserva tres restricciones:

1. la firma de cada barra no cambia;
2. una voz corporal o verbal mantiene la unidad temporal común;
3. la última barra de cada sección contiene una señal clara de llegada.

Si la improvisación destruye la forma, reduce primero densidad, no tempo.

## Oído y memoria formal

Escucha tu grabación sin contar en voz alta y señala:

- dónde percibes un cambio real de longitud de barra;
- dónde sólo cambia el fraseo;
- si el regreso a `4/4` resulta audible;
- si podrías reconstruir la ruta métrica desde el sonido.

Después repite contando. La comparación revela cuánto depende tu orientación de la cuenta verbal.

## Recuperación musical

En una ejecución real no siempre podrás parar.

Practica este protocolo:

`unidad temporal → siguiente 1 fiable → patrón neutro de la firma actual → reentrada musical`.

La recuperación cuenta como competencia. Una toma con un pequeño error bien recuperado puede mostrar más control musical que una toma frágil que sólo funciona mientras nada falla.

## Error frecuente: acentuar todos los grupos como una sirena

Los acentos exagerados son útiles para aprender la arquitectura, pero no son el destino final.

Reduce progresivamente el contraste hasta que la métrica siga siendo estable sin que cada comienzo de grupo necesite un golpe desproporcionado.

## AMPLIACIÓN

Crea una segunda forma de ocho barras manteniendo exactamente las mismas firmas, pero cambiando:

- agrupación interna;
- dinámica;
- densidad;
- orquestación.

Si ambas formas siguen siendo reconocibles, estás separando correctamente **métrica** de **superficie musical**.

## Criterio de avance

Puedes realizar una forma corta con dos o tres contextos métricos, conservar la continuidad temporal, hacer audible una intención de frase y recuperar la estructura después de un error sin detenerte.
