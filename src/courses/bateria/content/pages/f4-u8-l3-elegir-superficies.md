## Criterios

Compara:

`TIMBRE / CLARIDAD / MOVIMIENTO / DINÁMICA / FUNCIÓN / COSTE FÍSICO`

Preguntas:

1. ¿qué versión hace más clara la jerarquía de la frase?
2. ¿el recorrido físico aporta color o sólo riesgo?
3. ¿puedes volver a la caja sin retrasar la nota siguiente?
4. ¿el sticking sigue siendo funcional?
5. ¿mantendrías esta solución dentro de música o la elegirías sólo porque es más difícil?

## Sticking: conservar o cambiar deliberadamente

Conserva el sticking conocido por defecto. Si una ruta física concreta resulta poco funcional, prueba una alternativa **sólo después de identificar el problema** y explica qué mejora.

Cambiar sticking deliberadamente es una decisión de B8; cambiarlo accidentalmente por perderse no lo es.

## AMPLIACIÓN — un plato, una función

Puedes mover **un único acento** a un plato si:

- el acceso es ergonómico;
- la nota siguiente sigue entrando a tiempo;
- el cambio aporta contraste claro;
- el volumen sigue bajo control.

No hace falta crear un nuevo MusicXML para esta exploración.

## MÍNIMO PARA AVANZAR

- ejecutas o analizas ambas soluciones;
- eliges una mediante al menos un criterio musical observable;
- mantienes la distinción acento/superficie;
- no equiparas cantidad de piezas con calidad;
- si cambias sticking, puedes explicar la causa y el resultado.

## Registrar esta práctica

Anota `opción A / opción B → elección → razón → coste`.
