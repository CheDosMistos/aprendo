## Objetivo

Observar dos formas diferentes de sostener música completa:

- **Pieza A:** ruta guiada por chart dentro de una familia de backbeat;
- **Pieza B:** ruta predominantemente auditiva dentro de una familia shuffle.

> **DOS RUTAS ≠ DOS EXÁMENES DE DIFICULTAD.**

La comparación sirve para comprobar transferencia de funciones musicales, no para decidir cuál pieza “vale más”.

## 1. Pieza A — qué debe demostrar

En A prioriza:

- seguir la estructura;
- usar el chart sin quedar atrapado en el detalle;
- sostener un groove binario apropiado;
- mantener entradas y dinámicas;
- usar fills sólo donde tengan función;
- recuperarte si pierdes un detalle local.

El chart puede permanecer visible si esa es la condición declarada.

> **USAR CHART ≠ NO SABER LA PIEZA.**

La pregunta es si el chart ayuda a navegar música o sustituye completamente tu referencia interna.

## 2. Pieza B — qué debe demostrar

En B prioriza:

- conservar la subdivisión ternaria/shuffle;
- mantener backbeat y balance;
- recordar el mapa formal por escucha;
- anticipar transiciones importantes;
- recuperar la referencia después de un error;
- evitar que la notación convierta el feel en una sucesión rígida de figuras.

> **SHUFFLE ≠ CORCHEAS RECTAS CON OTRO NOMBRE.**

No endereces B para hacerla más fácil durante la evidencia final. Si el shuffle todavía no es sostenible, reduce densidad antes que cambiar la identidad temporal de la pieza.

## 3. Qué NO debe igualarse

No necesitas que A y B tengan:

- el mismo número de ayudas;
- la misma densidad;
- el mismo tipo de memoria;
- el mismo tempo;
- la misma dificultad coordinativa;
- los mismos fills.

Lo que debe ser comparable es la **función observada**: estructura, tiempo, dinámica y recuperación.

## 4. Contraste de familias

A y B ya aportan al portfolio de Fase 5 **dos familias estilísticas diferenciadas**:

`BACKBEAT BINARIO ↔ SHUFFLE / SUBDIVISIÓN TERNARIA`

Esto satisface la preferencia curricular de que las tres piezas finales representen al menos dos familias, sin obligar a Pieza C a fingir una identidad estilística adicional.

## 5. ESENCIAL AHORA — evidencia A

Realiza una toma completa de A con condiciones declaradas.

Después registra sólo:

- forma;
- tiempo;
- dinámica;
- recuperación;
- función del chart;
- un punto de mantenimiento.

No corrijas todavía B.

## 6. En otra toma o sesión — evidencia B

Haz lo mismo con B, respetando su feel.

Registra:

- estabilidad de shuffle;
- forma por escucha;
- dinámica;
- recuperación;
- un punto de mantenimiento.

No es obligatorio tocar A y B consecutivamente.

## 7. Comparación funcional

Completa:

| Dimensión | Pieza A | Pieza B |
|---|---|---|
| estructura | | |
| referencia temporal | binaria/backbeat | ternaria/shuffle |
| fuente principal | chart | escucha |
| dinámica | | |
| recuperación | | |
| ayuda necesaria | | |
| siguiente correctivo | | |

No hagas una media numérica entre ambas.

Si A funciona y B no, la conclusión no es “Fase 5 suspendida”. La conclusión es que **B identifica una dimensión crítica concreta** que necesita corrección.

## Criterio de avance

Puedes sostener A y B completas en versiones adecuadas a su objetivo, preservar sus diferencias de feel y explicar cómo cambia tu estrategia de aprendizaje sin perder estructura, tiempo, dinámica ni capacidad de recuperación.

**No existe BPM de aprobado.**
