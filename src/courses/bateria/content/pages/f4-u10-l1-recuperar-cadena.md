## Objetivo

Llegar a la integración sin volver a empezar Unidad 1–Unidad 9.

La regla es:

`RECUPERAR → DIAGNOSTICAR → CORREGIR UNA VARIABLE → RECOMPONER`.

## Paso 0 — configuración y escucha segura

Antes de tocar:

- confirma que asiento, pedales y superficies siguen accesibles;
- elimina una tensión o alcance claramente innecesario si aparece;
- aplica la gestión de escucha/carga adecuada al entorno.

No buscamos una postura milimétrica universal. Buscamos una configuración sostenible para la tarea.

## No repitas lo que ya funciona

Después de una pasada, clasifica:

- **DISPONIBLE:** puede entrar en la integración;
- **FRÁGIL:** necesita un correctivo breve;
- **NO DISPONIBLE HOY:** simplifica la versión y trabaja sólo esa unión antes de recomponer.

Un fallo local no invalida un cierre anterior.

## MÍNIMO PARA AVANZAR

- configuración y escucha segura están resueltas para esta sesión;
- Groove A es reconocible;
- recuerdas qué cambia en Variación B;
- Fill A conserva su duración y siguiente 1;
- puedes nombrar la prioridad dominante real;
- no conviertes la recuperación en repetir mecánicamente toda la Fase 4.

## Registrar esta práctica

Registra `A / B / Fill A → DISPONIBLE / FRÁGIL → correctivo elegido`.
