## Objetivo

Observar el paso **E3 → E4** sin confundir dificultad auditiva con dificultad notacional.

Aquí hacemos **dictado rítmico breve diseñado para la tarea**, no transcripción de una batería real.

## 1. Recuperación auditiva · 3–4 min

Si tienes una célula auditiva de la sesión anterior, intenta reproducirla antes de volver a escucharla. Si no, omite este bloque.

La recuperación sirve como evidencia separada; no es un requisito ritual para empezar.

## 2. Dictado A · 8–9 min

**EJERCICIO ORIGINAL CREADO PARA ESTE CURSO**

Proceso recomendado:

`ESCUCHAR → SEGMENTAR/RETENER → IMITAR → ESBOZAR/ESCRIBIR → TOCAR TU RESPUESTA`

Puedes:

- marcar el pulso;
- vocalizar si aclara;
- escribir o esbozar durante la escucha;
- repetir el estímulo.

No hay un número universal de escuchas “correctas”. **Registra cuántas necesitaste y qué cambió entre intentos.**

## 3. Dictado B · 8–9 min

Misma métrica y misma rejilla; cambia la densidad. Así una sola variable auditiva aumenta mientras la notación sigue siendo familiar.

## 4. Comparación localizada · 4–5 min

Después de revelar, compara por componentes:

1. marco de 4/4;
2. ocho posiciones de corchea;
3. ataques;
4. silencios;
5. legibilidad de tu escritura;
6. capacidad de tocar **lo que realmente escribiste**.

Si una discrepancia aparece, corrige el fragmento mínimo que permita probar tu hipótesis.

## Error frecuente

> “Lo toqué bien después de oír la solución, así que lo había oído bien.”

No necesariamente. El feedback puede haber sustituido la reconstrucción inicial. Conserva la primera respuesta como evidencia.

## MÍNIMO PARA AVANZAR

Al menos uno de los dos dictados produce una representación interpretable y puedes localizar si el límite principal estuvo en oído, memoria, escritura o ejecución. Las ayudas deben quedar registradas.
