## Objetivo

Producir **golpes simples de bombo** con una configuración que te permita volver a una posición útil para el siguiente ataque.

Hoy no buscas velocidad ni una técnica de talón concreta.

## Volver a H1 no es retroceder

Si el pedal parece obligarte a estirar, girar la pierna o perder equilibrio, el primer correctivo no es “practicar más”: revisa asiento, distancia y acceso.

No existe una altura de asiento, un ángulo de rodilla/tobillo o una tensión de muelle universalmente correctos para todo el mundo.

## EJERCICIO ORIGINAL CREADO PARA ESTE CURSO — GOLPE / VUELTA / PREPARA

1. Coloca el pie de forma cómoda sobre el pedal.
2. Produce **un solo golpe**.
3. Nota qué hace la maza y qué hace tu pie después del impacto.
4. Deja que el sistema vuelva a una posición desde la que puedas repetir.
5. Pausa.
6. Repite.

La pausa es parte del ejercicio: te permite observar la secuencia antes de encadenarla.

## Qué observar

`SONIDO / RETORNO / EQUILIBRIO / TENSIÓN`

- **SONIDO:** ¿el ataque aparece con una intensidad razonable sin tener que “pisar a muerte”? 
- **RETORNO:** ¿el pedal/maza vuelve de una forma que te deja preparar el siguiente golpe?
- **EQUILIBRIO:** ¿tu torso y la otra pierna siguen estables?
- **TENSIÓN:** ¿estás apretando de forma innecesaria muslo, pantorrilla o pie?

## Cambia una sola variable

Si algo falla, modifica sólo una cosa:

- distancia asiento–pedal;
- zona del pie sobre la plataforma;
- recorrido/intensidad;
- un ajuste razonable del pedal siguiendo su manual.

Después compara.

No cambies simultáneamente asiento, muelle, altura, técnica y tempo: perderías la causa del efecto.

## Seguridad

Carga muscular nueva puede sentirse como esfuerzo, pero **dolor persistente, hormigueo, entumecimiento, pérdida de fuerza/control o movimientos involuntarios persistentes** no se normalizan como técnica. Reduce o detén la carga y busca valoración profesional si persisten.

## MÍNIMO PARA AVANZAR

- produces golpes aislados repetibles;
- el pedal vuelve a una posición utilizable;
- conservas equilibrio razonable;
- puedes nombrar el principal problema si aparece;
- aplicas un correctivo de una sola variable;
- no necesitas velocidad alta para considerar el ejercicio útil.

## Registrar esta práctica

Anota `problema → cambio → efecto`. Completar la página no demuestra por sí solo H2 MÍNIMO.
