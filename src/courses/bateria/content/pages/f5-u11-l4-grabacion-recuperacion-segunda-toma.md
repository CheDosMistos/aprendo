## Objetivo

Convertir la grabación en **feedback accionable**.

> **GRABACIÓN = FEEDBACK. UNA TOMA FAVORABLE ≠ COMPETENCIA RETENIDA.**

La cámara o grabadora no decide si “tocaste bien”. Sirve para observar algo que durante la ejecución pudo pasar desapercibido.

## 1. Toma 1 — condición declarada

Registra una pasada completa de Pieza C e indica:

- versión de groove usada;
- si miraste chart;
- si usaste playback/click;
- qué ayuda tenías para las entradas;
- cualquier simplificación consciente.

No cambies esas condiciones antes de analizar la toma.

## 2. Elige UNA dimensión crítica

No intentes corregir todo a la vez. Escoge el problema que más afecte a la función musical:

- **FORMA:** te desorientas en una transición;
- **TIEMPO:** el pulso pierde estabilidad al cambiar de sección;
- **DINÁMICA:** B no contrasta o el outro no reduce;
- **RECUPERACIÓN:** un error local provoca varios compases de pérdida;
- **SONIDO/BALANCE:** una capa tapa sistemáticamente otra;
- **FILL/RETORNO:** el fill funciona aislado pero compromete la llegada al 1.

> **UNA DIMENSIÓN CRÍTICA PRIMERO.**

## 3. Cadena de diagnóstico

Usa la cadena estable del sistema de práctica:

`síntoma → hipótesis → prueba → correctivo → recomposición`

Ejemplo:

`síntoma: pierdo A' después de B → hipótesis: estoy pensando en el fill y no en el primer pulso de A' → prueba: tocar B sin fill → correctivo: reducir fill a un tiempo → recomposición: B 8 + A' 8 completos`.

La hipótesis puede ser incorrecta. La prueba sirve precisamente para averiguarlo.

## 4. Correctivo localizado

Trabaja sólo el fragmento necesario:

- 2–4 compases antes del problema;
- el punto de transición;
- 2–4 compases después.

Haz pocas repeticiones con atención. Cuando la relación sea comprensible, **vuelve a la pieza completa**.

No conviertas U11 en una colección de bucles desconectados de la forma.

## 5. Toma 2 — condiciones comparables

Graba otra pasada con las mismas ayudas principales que en la Toma 1.

Compara:

| Dimensión | Toma 1 | Toma 2 |
|---|---|---|
| forma | | |
| tiempo | | |
| dinámica | | |
| recuperación | | |
| sonido/balance | | |
| decisión musical | | |

No necesitas que todas mejoren. La pregunta principal es si el correctivo afectó a la **dimensión elegida** sin deteriorar gravemente las demás.

## 6. No elegir la “mejor toma” a posteriori

Guardar sólo la toma más favorable oculta información.

Conserva al menos:

- una toma diagnóstica;
- el correctivo usado;
- una segunda evidencia comparable.

Si la segunda toma empeora, también es información válida: quizá la hipótesis o el correctivo no eran adecuados.

## 7. Recuperación tras error

Durante la toma completa, si aparece un fallo local:

1. conserva o reconstruye el pulso;
2. identifica la sección actual o la siguiente referencia segura;
3. recupera groove mínimo;
4. devuelve después dinámica y detalle.

> **RECUPERAR ≠ BORRAR EL ERROR.**

La recuperación funcional permite que la música siga teniendo estructura.

## AMPLIACIÓN — retención

En otra sesión, realiza una nueva pasada sin revisar inmediatamente el correctivo. Si la mejora sólo existía durante el bloque de corrección, todavía no hay evidencia suficiente de retención.

## Criterio de avance

Puedes:

- registrar dos tomas bajo condiciones comparables;
- identificar una dimensión crítica con evidencia;
- formular y probar una hipótesis;
- aplicar un correctivo localizado;
- volver a la forma completa;
- explicar si el cambio se mantuvo o no.

No se exige producción profesional, una toma perfecta ni BPM prefijado.
