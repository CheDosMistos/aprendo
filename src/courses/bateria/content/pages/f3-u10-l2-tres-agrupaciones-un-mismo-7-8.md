## Objetivo

Cambiar conscientemente la organización interna de siete corcheas manteniendo el mismo **7/8**.

- `2+2+3`
- `2+3+2`
- `3+2+2`

Las tres suman siete corcheas. Cambia la agrupación/fraseo; **no cambia el compás**.

La partitura fija siete corcheas. La agrupación se aplica como consigna textual para no fingir una capa de acentos que el renderer no haya validado.

## Trabajo

1. Toca siete ataques iguales.
2. Organiza `2+2+3` sin mover la barra.
3. Repite con `2+3+2` y `3+2+2`.
4. Alterna una agrupación por compás.
5. Después cambia cada dos compases y escucha qué ocurre con la frase.
6. Reduce vocalización si el ciclo sigue claro.

No hay una agrupación “correcta universal” para todo 7/8. Estas tres son modelos pedagógicos accesibles.

## MÍNIMO PARA AVANZAR

Cambias entre al menos dos agrupaciones manteniendo el ciclo completo y puedes explicar qué cambió y qué se conservó.
